## 战斗渲染相关性

**总评：本文件不含 SpineSkeletonFastRenderer 渲染核心（锚点 0x70b8640/0x70b9bb0/0x70ba730/0x70bbdf8/0x70bc048 全部不在本文件，0x70b 段在 0x70b25f0 后断裂跳至 0x70c72d8），但含 spine 渲染上游的顶点色生成、裁剪与骨骼数据解析，以及通用的 MID 颜色参数入口——是顶点色来源链的关键一环。**

逐条证据：

1. **0x70b25f0（2396B）Spine 附件顶点累积器——顶点色来源的直接证据**（精读 196961–197327 行）：
   - 顶点色三重相乘公式（第 197241–197244 行）：
     ```c
     puVar2[1] = (char)(int)(fVar35 * fVar41 * fVar9  * 255.0);  // G = tintG * slotColorG * attachmentColorG * 255
     *puVar2   = (char)(int)(fVar36 * fVar32 * fVar10 * 255.0);  // R
     puVar2[3] = (char)(int)(fVar30 * fVar42 * fVar11 * 255.0);  // A
     puVar2[2] = (char)(int)(fVar37 * fVar40 * fVar8  * 255.0);  // B
     ```
     三个乘法源：param_5+8/0xc/0x10/0x14（**tint 色 RGBA**，外部传入）、`FUN_07124944(lVar26)` 返回的 **slot 颜色**（lVar26=槽位对象，经 FUN_07124954 可选存在性检查）、附件自带颜色（region/bounding-box 路径 `FUN_070e0eb4` 或 mesh 路径 `FUN_070e4fd0`，偏移 +8 起的 4 float）。
   - 逐顶点循环里还写入位置（param_6，y 乘 param_1 缩放）、UV（param_9）、每顶点 slot 色 3 float（param_11，来自 FUN_0712494c+8/0xc/0x10）、恒定 (1,0) 向量（param_8）；区域附件四边形索引固定 `{0,1,2,0,2,3}`（local_c0），索引累积基址 iVar25 递增（param_7）。
   - 结论：**战斗角色 Spine 的最终顶点色在此处合成（slot 色 × tint × attachment 色），呈字节写入顶点缓冲**；任何整体变色/脉冲若走顶点色，必须在 slot 颜色或 tint 来源处注入。本文件只见到消费端，slot 颜色的动画写入端（ColorTimeline 应用）不在本文件。
2. **0x7104eb8（1104B）SkeletonClipping::clipStart**：鞋带公式判绕向 + 多边形反转 + 裁剪交集（FUN_07106738/07105308），spine 槽位裁剪渲染路径，与顶点生成同管线（0x70b25f0 内以 local_4fc 标志调用它）。
3. **0x710a3b8（28764B）SkeletonJson::readSkeletonData**：解析 "color" 键 ×2、"blend"、音频事件等，骨骼/槽位初始颜色数据的源头加载。
4. **0x70e2644（3808B）timeline 曲线求值**：fmodf 循环 + 分段插值 + spine::Vector 分配，是 spine 动画 timeline（含 color timeline 的分段曲线）求值原语。
5. **0x6f67484（312B）`UMaterialInstanceDynamic::SetVectorParameterValue` 蓝图 thunk**（精读 181263–181312 行）：FName+FVector4 参数校验后直调 MID。**这是脚本侧动画材质颜色参数（含贴图原色↔纯黑脉冲若以向量参数实现）的通用入口**；本文件内未见将其与 spine 槽位/SpineSkeletonFastRenderer 关联的调用者——逐槽 MID 更新（0x70ba730/0x70bbdf8）不在本文件。
6. **0x68248cc GetTriCoordColor**：把骨骼网格三角形逐角顶点色（16 位索引寻址 + FWeakObjectPtr→USkeletalMeshComponent）喂给 Niagara VM——战斗特效粒子取角色顶点色的管线，非 Spine 本体。
7. **0x68f1cf8 `PushToRenderThread_Internal<FLinearColor>`** 与 **0x6905bdc UNiagaraDataInterfaceColorCurve**：LinearColor 数组/曲线进入渲染线程的通路（特效颜色动画基础设施）。
8. **pulse/正弦切换机制：本文件未发现**。全文件仅 0x72ce314 `CalcNTheta`（240B，几何曲线法线/角度计算）使用 sinf，与颜色脉冲无关；profile 关键词 pulse=0。贴图原色↔纯黑的切换逻辑不在本 part。

**无直接证据**：SpineSkeletonFastRenderer 构造/UpdateMesh/逐槽 MID 六个锚点地址全部缺失于本文件（python 全函数地址表校验），材质参数的逐帧正弦动画代码亦未出现；本文件承担的是 spine 顶点色的"生产端"与骨骼数据加载。
