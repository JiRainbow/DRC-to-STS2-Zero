## 战斗渲染相关性

**结论：本卷不含已闭合脉冲链的任何一环，但含 Spine 渲染的 3 个外围证据点。**

1. **0x70b25f0（spine 顶点色生产端）不在本文件**。本卷函数表按地址有序，0x70b25f0 落在空洞 `0x70b11d4 → 0x70b3660` 之间（bisect 验证）。但相邻区 0x70b11d4/0x70b6ccc 为 spine-cpp 黄金比例哈希(0x9e3779b9)查找表（SkeletonData find* 族），0x70b3660 为 spine 缓存释放，0x70b3778 之后为 SpinePlugin 组件代码 —— 即 0x70b25f0 所在编译单元（spine-cpp/SpinePlugin 渲染数据）的主体在本卷附近，函数本体在其它卷。
2. **0x6e2b57c（ReplaceDirectionalLight UFunction）不在本文件**：落在空洞 `0x6ba3fbc → 0x6e9a3a4`，且全文件字面 `6e2b57c` 0 次命中 —— 本卷无其调用方/thunk/注册。同理 grep `AzureCharColor|SetAzureCharColor|CharacterLightParams|FAzureMaterialParamSet|9dbadd4|a3e9720|97ee7cc|8eface8|8f59be8|8efb15c|9130678|9110a64|a0e5800|c6196b0` 全部 0 命中：AzureCharColor 值来源不在本卷。
