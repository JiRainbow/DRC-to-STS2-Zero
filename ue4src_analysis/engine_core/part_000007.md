## 战斗渲染相关性
**结论：本卷不含 Spine 顶点色生产端，也无 pulse/AzureCharColor 直系代码；但包含 Spine 渲染的 Lua 绑定层与两个混合材质名（ScreenBlendMaterial/MultiplyBlendMaterial）的读写点，属 Spine 颜色链路的"绑定/驱动层"证据。**

逐项核查（全部基于 grep 全文 0 命中 + 抽读代码）：
1. **0x70b25f0（spine 顶点色填充/darkColor RGB787 打包）不在本文件**：全文 `70b25f0` 命中 0。本卷覆盖 0x70ad318–0x70b0a6c、0x70b3350–0x70b53c0 等相邻段，0x70b0bc4–0x70b3350 缺口正好含该地址——其在相邻 part 文件。**相邻函数**：0x70b0a6c（TrackEntry 绑定）、0x70b3350（TrackEntry 数组释放）、0x70b53c0（spine 字符串导出）均属 SpinePlugin 运行时，紧贴目标函数地址区，追 0x70b25f0 时应优先翻 0x70b0bc4–0x70b3350 所属卷。
2. **0x6e2b57c（ReplaceDirectionalLight UFUNCTION thunk）不在本文件**：`6e2b57c` 全文命中 0。但其**反射注册侧痕迹在本卷**：`Z_Construct_UFunction_UAzureSceneImage_ReplaceDirectionalLight_Statics::NewProp_bReplace_SetBit` @ **0x6d030ac**（12B，bReplace 默认置 1，行 149138）——证明 ReplaceDirectionalLight 是 **UAzureSceneImage** 的 UFUNCTION（同卷同族：execSetOrthoWidth@0x6d02cbc、ReplaceMovableIndirectLighting@0x6d03110、InternalConstructor@0x6d034b4）。**谁调用 0x6e2b57c**：本卷无任何调用/引用；调用方需在含该地址的卷中找（其地址邻域 0x6e28710/0x6e2e3a8 在本卷，是 Lua 桥的 UCustomBoneComponent 绑定，说明 0x6e2b57c 所在卷同样承载 Lua→UAzureSceneImage/AActor API 桥）。
3. **SetAzureCharColor(0x9dbadd4)/FAzureMaterialParamSet::ApplyParams(0x97ee7cc)/UMID 参数族(0xa0e5800) 均超出本卷且全文 0 命中**；`AzureCharColor` 字符串全文 0 命中。本卷的对应物是 **CustomCharacterTexture** 类注册（AzureFacility，0x7066140 区域，行 197498）——角色自定义纹理的反射壳，未见颜色值来源逻辑。
4. **pulse**：全文 0 命中。
5. **ScreenBlendMaterial 混合材质（Spine 屏幕混合）3 处读点 + 1 处写点**：
   - 0x701904c：Lua 读 USpineSkeletonFastRenderer.ScreenBlendMaterial；
   - 0x701b724：另一 Spine 组件读 ScreenBlendMaterial（try/catch 包裹）；

   若战斗 Spine 发光/闪光通过屏幕混合材质实现，这 4 处是本卷内唯一的操作入口。
