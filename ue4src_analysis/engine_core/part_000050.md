## 战斗渲染相关性

本文件**没有** Spine/顶点色生产端/脉冲闪光代码（spine=0、pulse=0、VertexColor=0 次命中；已知地址 0x9dbadd4/0x9110a64/0xa3e9720/0xa0e5800/0x70b25f0 在本文件零引用），但**命中 Azure 替换光照系统的全局写入端**，是链条上关键一环：

1. **FUN_08f59be8 = 0x8f59be8（452B，★ 全局写入端）**：Azure 替换方向光渲染任务 Execute。证据（88182-88188 行）：
   `GAzureReplaceLightingParams._1_1_ = *(char*)((long)param_1 + 0x11); if (...) { lRam0c6196b8 = param_1[0xd]; _DAT_0c6196b0 = param_1[0xc]; DAT_0c6196c8 = param_1[0xf]; DAT_0c6196c0 = param_1[0xe]; }`
   —— 任务对象 +0x60~0x78 是两组 float4（第一组→0x0c6196b0/b8 = 方向光颜色，第二组→0x0c6196c0/c8，消费端 part_000047 里 0x0c6196b8 乘 0.31830987(1/π) 表明第二组含角度/方向量）。
2. **值来源链（跨文件闭合）**：蓝图 UFUNCTION thunk `FUN_06e2b57c`（0x6e2b57c，part_000013.c，524B）从 VM 读 (bool enable, FLinearColor color, FVector dir) → `AzureReplaceDirectionalLight`（0x8eface8，part_000039.c，1140B）：渲染线程则直写同四全局，否则构造图任务（task+0x11=enable，task[0xc..0xf]=两组 float4，任务默认色写入 0x3f800000 系常量）投递 RenderThread——任务布局与本文件 FUN_08f59be8 的读取完全对位，即 **0x8f59be8 就是 AzureReplaceDirectionalLight 入队的那个任务的执行体**。上游再往上是蓝图/脚本层（谁调该 UFUNCTION 需在游戏逻辑 part 中继续追）。
3. **FMobileBasePassMeshProcessor::Process = 0x8ecf448**：`GEnableAzureDepthFade` 开关（67609 行）给合格材质附加标记 4——Azure 半透明深度淡出（水面/角色边缘淡出类效果的开关端）。
4. **RenderAzureUsingPPRPass = 0x8efbeec**：每视图更新视图/不透明 BasePass/**方向光 uniform buffer 后再画 PPR pass**——平面反射画面也吃 Azure 替换光照。
5. **0x8f4d71c TMobileBasePassPSPolicyParamType**：把 `FMobileDirectionalLightShaderParameters` 绑进移动 BasePass 像素着色器——替换后的方向光色进 BasePass 的通道；**0x8f88140 区 FMobileDirectLightFunctionPS::FParameters** 元数据证明该 PS 的参数就是 `{MobileDirectionalLight(FMobileDirectionalLightShaderParameters), ReflectionCaptureData}`（93639-93643 行字段名直接可读）；**0x8f89740 FMobileRadialLightFunctionPS::SetParameters** 同族（点光灯光函数调制）。
6. **0x8f9f6e4 / 0x8f7af3c / 0x8f18f78**：Azure 平面反射遮挡跳过、平面反射点光跳过、NoSkipAlpha 代理名登记三个辅助钩子。
7. **MovieScene 颜色参数轨道（次要）**：`UMovieSceneParameterSection::RemoveColorParameter`（0x95a5b30）及 FColorParameterNameAndCurves/FColorParameterNameAndValue 族（0x95ee54c 等）——Sequencer 驱动材质颜色参数的存储/增删端；若战斗闪光走 Sequencer 轨道，这是其底座之一，但本文件内无直接证据。

与角色灯色 SetAzureCharColor(0x9dbadd4)/CharacterLightParams(0xa3e9720)/UMID 参数族(0xa0e5800)/spine 顶点色生产端(0x70b25f0) 无关联（全部零引用）。
