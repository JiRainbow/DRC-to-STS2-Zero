## 战斗渲染相关性

目标机制：战斗角色 Spine 贴图原色↔纯黑正弦颜色脉冲。**本文件无任何 Spine 符号**（FUNC 名与注释中 spine=0、pulse=0，仅 AddImpulse/ApplyImpulse 物理函数误命中 pulse 子串；Spine 顶点色生产端 0x70b25f0 在其他文件）。但本文件包含该机制必经的 **MID/MPC 材质参数管线**，且与兄弟文件已知底座地址完全同区：

1. **0xa10e24c FMaterialInstanceResource::RenderThread_UpdateParameter\<FLinearColor\>** (size 332) — 实读：InvalidateUniformExpressionCache + 在 TNamedParameter\<FLinearColor\> 数组（步长 0x24）按 FMemoryImageMaterialParameterInfo 匹配后覆写 16 字节颜色。若战斗角色脉冲通过 MID SetVectorParameterValue 驱动（每帧写入黑↔原色 FLinearColor），这是渲染线程最终接收端。与兄弟文件 MID 参数族 0xa0e5800 同属一条链（0xa0e11cc 游戏线程派发 → 0xa10e5f4 入队 → 0xa10e24c 渲染线程落地）。
2. **0xa0e46b4 UMaterialInstance::CopyMaterialUniformParametersInternal** (size 2644) — 实读：把基类材质的内联 uniform 表达式展开为 VectorParameterValue（0x34 步长含 FLinearColor）/ScalarParameterValue/TextureParameterValue 数组；地址紧邻兄弟文件 MID 参数族 0xa0e5800。
3. **0xa1230d4 FUniformParameterOverrides::SetTextureOverride** (size 1492) — 实读：FUniformParameterOverrides 覆盖表写入 + 渲染命令入队；与兄弟文件 **SetVectorOverride=0xa122df0 紧邻（相差 0x2e4 字节，同族）**，即本文件包含 FUniformParameterOverrides 族部分成员。
4. **0xa12e9f0 / 0xa12f448 MPCI::UpdateRenderState / DeferredUpdateRenderState** — 实读：两处直接调用 **FMaterialParameterCollectionInstanceResource::GameThread_UpdateContents（兄弟文件定位 0xa12dffc）**；0xa12dffc 本身落在本文件地址空档 0xa12dcc0–0xa12e764 内但无 FUNC 标记。若脉冲走 MPC 全局参数（如全局角色闪白/闪黑集合参数），此为游戏线程推送路径。
5. **0xa043364 UKismetMaterialLibrary::GetVectorParameterValue** (size 2420) — 实读：蓝图侧读取 MPC 向量参数 → MPCI::GetVectorParameterValue；逆向时可在其上设观察点确认哪些 MPC 参数被游戏读取。
6. **0xa1323dc FMeshVertexPainter::PaintVerticesSingleColor** (size 292) — FLinearColor 顶点色整体刷写（UStaticMeshComponent）；顶点色基础设施，但对象类型为静态网格而非 Spine 网格。
7. **0xa342384/0xa3434c0/0xa343b64 FColorVertexBuffer ctor/GetVertexColors/BindDefaultColorVertexBuffer** — 通用顶点色缓冲（TStaticMeshVertexData\<FColor\>，4B/顶点）；与 Spine 无关，仅作顶点色基建参照。
8. 粒子线（0xa213a08 TParticleSimulationPS::SetParameters、0xa23c5b4 CalculateParticleTransform、0xa224374 UParticleModuleLocationSkelVertSurface::Spawn）：战斗特效粒子管线，非颜色脉冲机制本体。

结论：本文件不含 Spine/脉冲实现，但含 **MID 线性颜色参数的完整 游戏线程→渲染线程 更新链（0xa0e11cc→0xa10e5f4→0xa10e24c）与 MPC 推送调用方（0xa12e9f0/0xa12f448→0xa12dffc）**，均为兄弟文件所发现底座的直接上下游，逆向脉冲驱动方（谁在每帧调 SetVectorParameterValue/MPC 更新）时应将断点/交叉引用重点放在 0xa10e24c（FLinearColor 落点，回溯调用者即可找到驱动源）与 0xa12dffc 的调用方。
