## 战斗渲染相关性
**已知五个 Azure 颜色函数（SetAzureCharColor=0x9dbadd4、CharacterLightParams=0xa3e9720、AzureIndirectCharacterLightingColorScale=0xa3f743c、bOverride_AzureCharLightDesaturation=0xa922c70、SetAzureOutlineColor=0xa9040a4）均不在本文件地址域（0x8da45f0–0x9b691ac）内，grep azure 相关符号仅命中下列游戏层痕迹；spine 关键词 0 命中（profile keywords spine=0，全文 grep "spine" 无结果）；UMID 参数族(0xa0e5800)、uniform 求值(0xa0fe0a4)、MID 渲染线程落点(0xa10e24c)、Lua VM(0xabd1bb0)、spine 顶点色生产端(0x70b25f0)、Sequencer 材质轨道执行端(0x958daa0) 亦均在域外，本文件无 0x958dxxxx 段函数。逐条证据：**

1. **RenderAzureOutlinePass 调用点 — FMobileSceneRenderer::RenderForward 0x8f75d44，行 39972**：`RenderMobileBasePass(...); RenderAzureOutlinePass(param_1,param_2,param_3,param_4);` —— Azure 描边 pass 被硬编码进移动前向管线、紧跟 BasePass 之后、RenderOcclusion 之前。SetAzureOutlineColor(0xa9040a4，域外)写入的颜色大概率由此 pass 消费；该 pass 的函数体不在本文件，建议在其定义文件反查 RenderForward 的调用约定与所用材质。
2. **RenderAzureUsingPPRPass 调用点 — 同函数，行 40210**：受 param_1[0x431]/[0x436]/[0x43f] 条件门控的 Azure PPR（平面反射/角色特殊渲染）pass。
3. **FAzureMaterialParamSet::ApplyParams — 0x97ee7cc (1928B)，行 146143–146560**：游戏层"材质参数集→MID"写入器。证据：非 MID 时 `builtin_memcpy(local_98,L"_Dynamic",0x12)` + MakeUniqueObjectName + UMaterialInstanceDynamic::Create；随后三个数组循环：SetTextureParameterValue(行146291)、**SetVectorParameterValue(行146397，FLinearColor 整体 R/G/B/A 写入)**、SetScalarParameterValue(行146505)。这是"谁在每帧写材质参数 Value R/G"的候选写入形态：FLinearColor 值存在结构体向量参数数组（this+0x60, stride 0x24：FName 参数名 + FLinearColor 值）。**注意：本文件只有 ApplyParams 与 TCppStructOps 反射桩（行149057+），参数集的填充/动画驱动端不在此文件**——应沿 FAzureMaterialParamSet 的引用（其它 part 文件）找填充方，与 SetAzureCharColor 的值来源连线。
4. **UAzureMovieSceneEventTrack — 0x969be80/0x969bf88/0x969c0b0**：游戏层 Sequencer 事件轨道 UClass（继承 UMovieSceneEventTrack）。战斗/演出时间轴事件经 FEventTrackExecutionToken::TriggerEvent（0x95b9248 起，行93738 附近为日志 lambda）→ UMovieSceneEventSystem::TriggerEventWithParameters 0x9648df4（解析 FFieldPath 后带 payload 调用蓝图/原生函数）落地。若角色颜色脉冲由 Sequencer 事件驱动，事件最终走此链。
5. **Sequencer 颜色轨道属性系统（与 pulse 颜色动画直接同族）**：FColorTokenProducer::CacheExistingState 0x95e9bb4、~FColorTokenActuator 0x95e9458、TMovieSceneBlendingActuator<FLinearColor>::Actuate 0x95e9a84、ConstructAndDispatchWhenReady<...EColorPropertyType...> 0x95c148c、InvokeSetterFunction<FColor> 0x95c21b8 —— Sequencer 每帧把 FLinearColor/FColor 写入对象属性的执行端（0x95c1–0x95ea 区，与域外 0x958daa0 材质轨道执行端同属 MovieScene evaluation 家族，地址相邻）。
6. **FWidgetMaterialHandle::GetMaterial — 0x973e494**：UMG 材质句柄分发，识别自定义类型 "AzureSlateMeshData"（TMaterialStructType<FAzureSlateMeshData>，行128366–128380）→ FAzureSlateMeshData::GetMaterial。UI 侧游戏自定义网格材质入口，与战斗无关但属 Azure 材质体系。
7. **颜色绑定**：UColorBinding::GetSlateValue 0x9740948 / IsSupportedDestination 0x97406f0 —— UMG 控件颜色绑定，属 UI 颜色通道。
8. **Azure 命名 CVar 族 — _INIT_789 0x954464c**：CVarAzureEnableImmediatePhysics=p.EnableImmPhy、CVarAzureAnimTargetFrameRate=p.AnimFrameRate 等全部为 AnimNode RigidBody 物理调参（行91190–91290），佐证 "Azure" 是本作项目代号；与 0x9518ae4 FAnimNode_RigidBody 同系统，不含颜色逻辑。

结论：本文件不含 AzureCharColor/CharacterLightParams 的定义与消费者，但包含 (a) 消费 Azure 描边色的管线挂点（RenderForward 内两处调用），(b) 与"写材质参数 Value R/G"形态吻合的游戏层参数应用器 FAzureMaterialParamSet::ApplyParams（值来源需在别处），(c) Sequencer 颜色/事件轨道执行端。追"AzureCharColor 值从哪来"应转向包含 0x9dbadd4 的 part 文件，并以 FAzureMaterialParamSet 的构造/填充点为交叉验证。
