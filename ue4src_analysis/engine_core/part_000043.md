## 战斗渲染相关性

**无**。依据：

1. **目标地址全部不在本卷地址域**：0x70b25f0（spine 顶点色生产端）、0x70b2424、0x70c0d30（调度器）、0x70b1554（顶点色分批）、0x6e2b57c（ReplaceDirectionalLight exec thunk）、0xa0e5800（UMID 参数族）、0x9dbadd4（SetAzureCharColor）——均落在 0x6e2xxxx–0x70cxxxx 与 0x9dbxxxx–0xa0exxxx 区，而本卷为 **0x84113b8–0x8da2068**，与已闭合链各地址**无地址相邻区**（最近距离 >0x1350000）。对六个地址 hex 串全文 grep 均 0 命中。
2. **Spine/pulse/顶点色证据为零**：全文 `spine` 0 命中、`pulse` 0 命中（profile keywords 一致）；函数名中 Color/Tint/Pulse/Flash/Blink 均无命中；`azure` 仅 3 处，全为 `GAzureIsInFlushShaderCacheState`/`GAzureFlushShaderCacheFlag`（shader cache 刷新状态全局，宿主 0x849d0e8，见关键函数表），与 SetAzureCharColor 颜色值来源无关。
3. **"color/vertex/material" 关键字命中（469/337/456）全部来自 Chaos 物理与 RHI 着色器元数据语境**（如 BASEPASS_ATMOSPHERIC_FOG、距离场/阴影 CS 参数名、FMaterialRenderProxy 出现在 BuildMeshDrawCommands 模板签名中），不存在逐顶点颜色分批、正弦颜色脉冲或 Dark 二级 tint 的任何实现痕迹。
4. 本卷 `particle` 命中为 `Chaos::TGeometryParticlesImp/TPBDRigidParticles/FBVHParticles`（物理粒子），非 Niagara/特效粒子。

结论：本卷为 **Chaos 物理引擎 + 着色器管线缓存/元数据底座**卷，对战斗 Spine 颜色脉冲渲染链无直接贡献；仅 0x849d0e8（Azure shader cache 刷新派发）与游戏渲染系统有间接关系（着色器重编译触发路径可能最终落到 ReplaceDirectionalLight 所在的 Azure 场景系统，但本卷不含调用关系证据，0x6e2b57c 的调用方需在 0x6e2xxxx/0x70bxxxx 附近卷中查找）。
