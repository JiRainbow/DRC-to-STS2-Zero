## 战斗渲染相关性

**结论：已闭合链的 5 个目标地址全部不在本卷**（`grep -i "6e2b57c|70b25f0"` 零命中；0x9dbadd4、0x97ee7cc、0xa0e5800 本就在 0x9/0xa 段，超出本卷地址域）。且：
- `pulse`/`ulse` 全文 0 命中（profile 的 pulse:8 来自二进制字符串，反编译文本中不存在）；
- `SetAzureCharColor`、`AzureCharColor`、`ApplyParams`、`MaterialParamSet`、`DirectionalLight` 全部 0 命中。
