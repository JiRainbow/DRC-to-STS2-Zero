# part_000021.c 分析

## 概况

- **函数数**:4067 个(标记行 `// ==== FUNC` 实测 4067,与 profile 一致)
- **地址域**:0x71ae400 – 0x84108b0(跨约 19.2MB 地址空间,文件 8MB)
- **模块定性**:典型的引擎底座杂卷。由以下互不相关的 UE4 模块组成:
  - **CoreUObject/序列化**:FLinkerLoad/FLinkerSave/UMetaData/FCoreRedirects/FObjectExportSortHelper/FLinkerPlaceholderBase/SortExports/GetObjectsWithOuter/TFastReferenceCollector(GC)/StaticLoadClass/UScriptStruct(456 处)

  - **数学库**:Eigen::SparseQR(174)、gte::DCPQuery、ShewchukExactPredicates(精确谓词)
  - **Vulkan RHI**:FDynamicRHI/FVulkanDynamicRHI(38+13)、FVulkanRenderTargetLayout、RHICreateGraphicsPipelineState、FVulkanPipelineStateCacheManager、FGfxPipelineDesc、FMemoryManager::AllocateBufferMemory、SelectAndInitDevice

  - **OnlineSubsystem**:UPartyBeaconState、IOnlineSession(7)、IAP(UInAppPurchaseCallbackProxy2)、"OSS: " 日志前缀(22 处)
  - **Android 平台层**:FAndroidMisc::MessageBoxExt、android.* 控制台变量、Manifest_NonUFS/UFSFiles_Android.txt
  - **输入**:EKeys 全表 FName 初始化(1288 处 EKeys:: 引用,集中在 _INIT_469)
  - **音频**:UModularSynthComponent(9)、USynthComponentMonoWaveTable(7)、UAudioImpulseResponse、Synthesis

## 战斗渲染相关性

**无。** 依据(全部实测):

1. **地址域不覆盖**:目标链全部地址均在本卷范围 [0x71ae400, 0x84108b0] 之外——0x70b25f0、0x70b2424、0x70c0d30、0x6e2b57c、0x718e77c 均小于起点 0x71ae400(0x718e77c 距起点约 0x1FC84,属上一卷);0x9dbadd4(SetAzureCharColor)大于终点。对 `6e2b57c|9dbadd4|0c6196b|70c0d30|70b2424|70b25f0|718e77c` 七串直接 grep 本文件 = **0 命中**,即本卷没有任何代码调用或引用这些本体。
2. **"azure" 仅 4 处且与角色颜色无关**:GAzureRenderDocRunningFlag(_INIT_451@0x7b50918 内 `c.rd` RenderDoc 采集标志,行 152886)、GAzureDestroyStructFlagTlsSlot(行 152892,TLS 槽)、GAzureCheckUpdateFlagsBeforeModify(行 201201/216237/216883,是 Slate SButton/SWidget tick 中刷新 widget 标志前的全局守卫)——均为引擎级全局标志,无颜色语义。
3. **无材质参数/顶点色/spine/pulse 痕迹**:`spine`=0、`pulse`=0(profile 与全文 grep 一致);`MaterialInstanceDynamic|SetVectorParameterValue|KismetMaterialLibrary`=0;SetColorParameter/SetColorParameterValue/SetScalarParameterValue=0。599 处 "vertex" 全部属于 FDynamicMesh3/TDynamicMeshOverlay/Chaos/Eigen 的几何处理,不是渲染顶点缓冲;381 处 "color" 全部是 Slate ColorAndOpacity/SThrobber/SEditableTextBox、FColorList、UPaperTerrainComponent::execSetTerrainColor(0x724e61c)、FLinearColor 构造——无一涉及 Azure 角色颜色、Dark 二级 tint、脉冲闪光或顶点色填充。
4. **唯一沾边的 render-proxy 函数**:FCableSceneProxy::BuildCableMesh(0x7833cc4,CableComponent 缆绳动态网格),函数体 0 处颜色操作,与战斗角色渲染无关。

**结论**:追 Spine 颜色脉冲链路时,本卷可直接跳过;0x70b25f0/0x70b2424/0x70c0d30 本体与 0x6e2b57c 的调用方请到地址域 0x6exxxxx–0x71axxxx(上一卷)检索,0x9dbadd4 在更高地址段。
