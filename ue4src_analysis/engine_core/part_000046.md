# part_000046.c 分析

## 概况

- **规模**：8,014,801 字节 / 198,121 行 / 3,011 个函数。
- **地址域呈两段断层分布**（对全部 FUNC 标记按地址排序证实）：
  - 段 A `0x86dee24 – 0x8e9d6ac`：Chaos 物理引擎（GJK/EPA 碰撞模板、刚体粒子、PBD 簇、隐式体）、FMemory/FMemStackBase/FMemoryImageAllocatorBase 内存底座、FShaderParametersMetadata/FTypeLayoutDesc/ETypeLayoutInterface（着色器参数元数据 + Freeze 序列化布局）、FShader/FGlobalShader/FShaderMapResource/FRenderResource 基础设施。
  - 段 B `0x9233d34 – 0x938eba4`：RDG 高层 pass（VolumetricCloud、VoxelizeVolume、TranslucentLightingInject、ResolveFilterWide）、FShaderCompilerDefinitions/FGenericDataDrivenShaderPlatformInfo 着色器编译、FVirtualTextureSystem、Landscape/Foliage/AugmentedReality 模块的 UObject 反射注册（Z_Construct 家族 87 个）、FVariableRateShadingImageManager、IConsoleManager。
- **主要类（按符号量归纳自 profile + 抽样核实）**：Chaos（13,547 符号，TImplicitObjectScaled/Instanced、TGJKCoreShape、GJKRaycast2/EPA 模板族）、FMemory(850)、FShaderParametersMetadata(650)、FMemStackBase(602)、FMemoryImageAllocatorBase(598)、FGenericDataDrivenShaderPlatformInfo(287)、FShaderCompilerDefinitions(254)、FShader(224)/FShaderMapResource(217)/FShaderParameterBindings(194)、IConsoleManager(164)、FComputeShaderUtils(157)、FRenderResource(114)、FVariableRateShadingImageManager(106)、UObject(96)。
- **定位结论**：这是 UE4 移动端渲染器 + Chaos 物理的底层支撑文件（engine infra），不是游戏业务代码；与战斗角色渲染链只有间接关系（见"战斗渲染相关性"）。

## 战斗渲染相关性

**结论：战斗角色 Spine 颜色脉冲渲染链在本文件中不存在**（该文件 relevance 定为 engine，仅引擎底座）。

依据（均经实际验证）：
1. **地址断层**：全文 3,011 个 `==== FUNC` 标记按地址排序后存在连续空洞 `0x8e9d6ac → 0x9233d34`。已闭合链中的 AzureReplaceDirectionalLight(0x8eface8)、渲染任务(0x8f59be8)、消费端(0x8efb15c/0x9130678)、SetAzureCharColor 写点(0x9110a64) 全部落入该断层；SetAzureCharColor 本体(0x9dbadd4)、CharacterLightParams(0xa3e9720)、FAzureMaterialParamSet::ApplyParams(0x97ee7cc)、UMID 参数族(0xa0e5800 区)、spine 顶点色生产端(0x70b25f0) 则超出文件地址域上限 0x938eba4。
2. **直接 grep 0 命中**：`8eface8`、`8f59be8`、`8efb15c`、`9130678`、`9110a64`、`6e2b57c`、`9dbadd4`、`a3e9720`、`97ee7cc`、`c6196b0/b8`、`ReplaceDirectionalLight`、`SetAzureCharColor`、`AzureCharColor`、`CharacterLightParams` 在全文均无匹配。即：**0x6e2b57c（ReplaceDirectionalLight 的 UFUNCTION）在本文件没有任何调用方/注册点；AzureCharColor 的值来源也不在本文件**。
3. **无 Spine**：`grep -i spine` 0 命中；`pulse` 仅命中 Chaos 冲量（Impulse），非颜色脉冲。
