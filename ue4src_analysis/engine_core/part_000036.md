## 战斗渲染相关性

**无直接战斗渲染内容。** 依据：

1. **关键词全零**：全文件 grep `Spine|spine|pulse|Pulse|VertexColor|TintColor|FlashColor|SetFillColor|SetContentColorAndOpacity`（后两者 0 命中）；`AzureCharColor`、`ReplaceDirectionalLight`、字面地址 `0x70b25f0/0x70b2424/0x70c0d30/0x6e2b57c/0x9dbadd4/0x9110a64` 均 **0 命中**。
2. **地址域不覆盖**：本卷 0x7fcc85c 起，顶点色生产端 0x70b25f0/0x70b2424、调度器 0x70c0d30（0x70xxxxx 区）与 exec thunk 0x6e2b57c（0x6exxxxx 区）都不在本卷区间，且文件内亦无对这些地址的任何引用。三个专项问题的回答：
   - ① 0x70b25f0/0x70b2424/0x70c0d30 本体**不在本文件**（Dark 二级 tint 值来源无法从本卷追）；
   - ② 0x6e2b57c 的调用者**不在本文件**（0 命中）;
   - ③ AzureCharColor 的值来源**不在本文件**。
3. **本卷 "Azure" 命中（10 处）均为 Slate UI 失效优化**，与角色颜色无关：全局标志 `GAzureCheckUpdateFlagsBeforeModify`（SWidget::Paint@line518、SWindow::Construct@line2433、STooltipPresenter::Construct@line53548、SBorderNoVolatile@line54591、SScrollBox@line59361——paint 前按 widget 标志位 0x61>>4 决定是否 UpdateWidgetFlags）；CVar `Slate.GAzureInvalidationBoxOptimize_AzureUpdateChildrenOrder`→GAzureUpdateChildrenOrder（FUN_082a6008@0x82a6008）；`AzureGetScrollBoxScrollPanel`@0x825161c。可确认游戏引擎 fork 的 "Azure" 前缀命名同时用于 UI 失效系统与战斗场景类（UAzureSceneImage 等），但本卷只含 UI 侧。
4. **颜色相关函数全部是 Slate 编辑器/样式**，与 Spine 脉冲机制无关：SColorPicker 族（0x834f48c 起）、SColorThemesViewer::Construct@0x8365020、SThemeColorBlock 族（0x835a778 Color/0x835c46c BorderBackgroundColor/0x835c738 HandleBorderColor 等）、FTableRowStyle::operator=@0x800b73c、SMultiBoxWidget::AddBlockWidget 内 ColorAndOpacity 槽（0x80f6810，通用 UI 属性）。OneColorShader（0x8481008 注册段）是引擎标准纯色全屏 shader，用于清屏/调试绘制，非角色变色通道。
