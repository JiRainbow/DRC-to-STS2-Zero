# part_000056.c 分析

## 概况
- 规模：约 8.0 MB，214,494 行，4769 个函数；地址域 **0x9001374 – 0x9b8cce0**。
- 本质：UE4 引擎的"杂烩卷"。按符号与签名注释归纳，主体为 **UE::MovieScene（Sequencer）**（MovieScene 符号 3661 个：实体系统 FEntityManager/FSequenceUpdater/FEntitySystemRunner、属性系统 FPropertyAccessSystem/UMovieScenePropertyInstantiatorSystem、PreAnimated 状态族、FSystemInterrogator、MovieSceneCapture），外加：

  - **动画**：FAnimNode_BoneDrivenController / FAnimNode_AnimDynamics / FAnimNode_BlendSpacePlayer；

## 战斗渲染相关性
**本卷不含 Spine/顶点色生产端本体，但含 1 个直接相关的 Azure 材质参数动画调用方与 Sequencer-Material 参数动画底座。**逐项证据：

1. **0x97ef034 `FAzureSlateMeshData::OnPlay`（行 143338-143456，已精读）**——★本卷最有价值的发现：
   - 调用 `FAzureMaterialParamSet::ApplyParams((FAzureMaterialParamSet*)(this+0x10), *(UMaterialInterface**)(this+8))`（行 143376）——**这是 ApplyParams=0x97ee7cc 的一个确认调用方**；
   - 返回值按 `UMaterialInstanceDynamic::GetPrivateStaticClass()` 做 IsA 检查；失败/无效时用 `MakeUniqueObjectName` + `UMaterialInstanceDynamic::Create(基材质, outer, 名字)` 生成名为 **`<材质名> + "_Dynamic"`** 的 MID（行 143404 builtin_memcpy(pwStack_88,L"_Dynamic",0x12)），存入 this+0x100 的 TWeakObjectPtr；
   - 结构推断：FAzureSlateMeshData = {+0x8 源 UMaterialInterface*, +0x10 FAzureMaterialParamSet 参数集, +0x100 生效 MID 弱指针}——即"参数集→MID"的封装，用于 Slate 网格（SMeshWidget）渲染。**回答任务问题②（谁调用 ApplyParams）：本卷证实 FAzureSlateMeshData::OnPlay 是其调用方之一**；其余调用方应在 0x97ee7cc 所在卷及引用 FAzureMaterialParamSet 的卷继续找。
2. **FAzureMaterialParamSet 本体**：本卷只有 `~FAzureMaterialParamSet`（0x? 位于行 147822 附近）、`Z_Construct_UScriptStruct_FAzureMaterialParamSet_Statics::NewStructOps`（行 147721）及 TCppStructOps boilerplate——结构注册在 /Script/MovieSceneTracks；**ApplyParams 定义不在本卷**（0x97ee7cc 处无 FUNC 头）。
3. **UAzureMovieSceneEventTrack**：仅 `UClassCompiledInDefer` 注册（0x96a8340 _INIT_798 内，行 126315-126322，/Script/MovieSceneTracks）。Azure 自定义 Sequencer 事件轨道——Sequencer 事件轨道是蓝图 UFUNCTION（如 0x6e2b57c ReplaceDirectionalLight 类事件）被动画触发的机制底座；**但本卷无其方法体，也无对 0x6e2b57c 的调用**（该地址低于本卷区间，grep 全文件无命中）。
4. **Sequencer-Material 参数动画（与 Azure 颜色动画同族）**：0x95bb588 `FPreAnimatedMPCScalarToken::RestoreState` 与 0x95bb67c `FPreAnimatedMPCVectorToken::RestoreState` 分别调用 `UMaterialParameterCollectionInstance::Set{Scalar,Vector}ParameterValue`（行 104273/104311）——Sequencer 动画材质参数集合的还原路径，属 UMID/MPC 参数动画家族（0xa0e5800 UMID 参数族所在卷的"同类机制"旁证，地址不相邻）。
