## 战斗渲染相关性

结论：**本文件不含 Spine 渲染、顶点色生产、颜色脉冲机制本体**（spine 关键词 0、无 LinearColor 动画驱动、pulse 全为物理/音频语义）。但它是 **Azure 角色光照颜色系统的引擎侧底座之一**，证据逐条：

1. **0xa3f743c**（zzAppendMemberGetPrev）：`AzureIndirectCharacterLightingColorScale` 注册为 **FInstancedViewUniformShaderParameters 的 uniform 成员，offset 0x9e0**。这是引擎渲染层消费 Azure 角色光照颜色的直接落点——角色颜色缩放经 ViewUniformBuffer 进 shader。对追查"SetAzureCharColor 的值流向"的意义：**游戏层写入的 Azure 角色颜色最终会汇入 FViewUniformShaderParameters 每帧上传**（UpdateViewUniformBuffer 路径），MID 参数与 view uniform 是两条并行通道。本文件还含同结构体另外 36 个 zzAppendMemberGetPrev 成员注册 + StaticStructMetadata x2（成员链表的其它环节分散在相邻 part）。
2. **0xa40b198**（_INIT_954 内）：注册 **r.AzureClipProjectionMatrix**（默认 on）——Azure 裁剪投影矩阵引擎开关，属角色渲染裁剪底座。
3. **0xa922c70**：FPostProcessSettings 的 **bOverride_AzureCharLightDesaturation** 反射属性——存在"AzureCharLightDesaturation（角色光去饱和）"后处理参数，是 AzureCharColor 系统的 PP 侧配套（值本身注册在别处）。
4. **0xa90bc14 / 0xa905a30 / 0xa8c7064**：`UPrimitiveComponent::SetAzureOutlineColor`、`AzureResetILCData`、`UParticleSystemComponent::AzureSetLODLevelBP` 的**反射注册与 BP thunk**（实现体不在本文件）——证实 UPrimitiveComponent 上挂有 Azure 描边色 / ILC 数据重置接口，与角色颜色系统同族。
5. **0x9d10a84**：`UAzureTexture2DReadable::CopyMipData`——Azure 命名空间的引擎纹理辅助类。
6. 材质参数相邻底座：**0xa877ccc / 0xa878578**（MID 的 K2_GetVector/SetScalar ParameterValueByInfo 的 FFrame thunk）、**0x9dd0084 / 0xa909640**（SetDefaultCustomPrimitiveDataVector3/4）——是参数传递的解包层，**不是**"每帧写 Value R/G"的驱动端；驱动端需到调用 SetVectorParameterValue 的游戏层 part 找。
7. 用户提供的已知底座地址核对：SetAzureCharColor=0x9dbadd4、CharacterLightParams=0xa3e9720、SetAzureOutlineColor 实现体=0xa9040a4、UMID 参数族=0xa0e5800 区、uniform 求值=0xa0fe0a4、MID 渲染线程落点=0xa10e24c、Lua VM=0xabd1bb0——**均不在本文件**（0x9da/0x9db/0x9dc、0xa0e-0xa11 多个子区间实测无函数，属其它 part；本文件只有 0xa3e-0xa41 区间的 view-uniform 元数据与 0xa90-0xa92 区间的 Azure thunk/注册）。spine 顶点色生产端 0x70b25f0 在地址域之外。
8. 可借道的机制提示：0xa40b198 里注册的 `r.DiffuseColor.Max/r.Roughness.Min/Max`（"Allows quick material test by remapping..."）是引擎原生的快速材质颜色重映射 CVar，与贴图↔纯色切换调试相关但非游戏脉冲机制本体。
