# part_000051.c 分析

## 概况
- 函数数：4384（与 profile 一致，CSV 索引已生成）。
- 地址域：0x8b1eea8 – 0x9deef0c（约 20MB 代码空间）。
- 文件构成（按 FUNC 名归纳 + 抽样精读）：
  - **Chaos 物理碰撞**：文件头部 0x8b1eea8–0x8b88054 一大段 GJK/EPA/OverlapQuery/SweepHelper/TSQVisitor 模板实例（球/胶囊/盒/凸体），Chaos 符号共 1580 处（profile）。
  - **FMemory/Freeze/MemoryImage**：FMemory 1669 处、Freeze 902 处——主要是 641 个 `StaticGetTypeLayout()`（shader/结构体内存镜像类型布局注册）与 `zzAppendMemberGetPrev`（84 个）等反射/序列化样板。

  - **MovieScene/Sequencer**：MovieScene 1313 处符号（UMovieScenePiecewiseFloatBlenderSystem、FMovieSceneColorSection 等）。

  - **Audio**：FAudioDeviceManager::ToggleAudioMixer 等 36 个。
  - **Azure 定制**（游戏方定制层，本卷零散分布 5 处，见"战斗渲染相关性"）。
- 主要类（:: 符号归纳）：FMemory、Chaos::*、UE::MovieScene::*、FShader/FShaderCompilerDefinitions/FShaderParametersMetadata、FScene/FSceneRenderer/FMeshDrawCommand、ULightComponent/FLightSceneInfo、UWidget/UDynamicEntryBox、FAudioDeviceManager、FAzureMaterialParamSet/FAzureOutlinePassVS/UAzureMovieSceneEventTrack/FAzureSlateMeshData。
- profile 关键词计数：spine=0、pulse=0、fight=0；material=919、color=908、vertex=607 —— 但其中 vertex/color 命中几乎全部来自 shader 参数名字符串与 Chaos/MovieScene 符号，**无任何 Spine/顶点色生产端代码**。

## 战斗渲染相关性
**结论：本卷不含 Spine 颜色脉冲机制本体，但含 Azure 角色颜色系统的 4 个外围件（结构反射、描边 VS 布局、光照附件根更新、Sequencer 事件轨道），且两个重点地址恰好落在本卷地址域的"反编译空洞"里。**

逐条 addr+证据：
1. **0x9829938 FAzureMaterialParamSet::operator= (368B)** — 已精读。FAzureMaterialParamSet 结构实测：三组 4 字节数组（+0x40/+0x90/+0xe0 为堆指针，+0x48/+0x98/+0xe8 为 Num，+0x38/+0x88/+0xd8 为内联小缓冲），中间 +0x50、+0xa0 两个成对复制子结构。这是 Azure 角色材质参数集（正是 ApplyParams 的宿主类型）的**值存储端**；但它的"值来源"（谁填充数组）不在本文件。
2. **0x9831974 Z_Construct_UScriptStruct_FAzureMaterialParamSet (76B)** + 0x9831914 EmptyLinkFunction — FAzureMaterialParamSet 被注册为 UScriptStruct ⇒ 可被 Sequencer/蓝图动画驱动（与 UAzureMovieSceneEventTrack 0x969bd04 呼应）。
3. **0x8c2cdbc FAzureOutlinePassVS::StaticGetTypeLayout (356B)** — 已精读。Azure 描边 pass 的 VS（FMeshMaterialShader 派生），shader 参数 `AzureOutlineWidth`（FShaderParameter）。证明描边渲染管线在本作存在；但 AzureOutlineColor_WidthInA 读端 0x6fccf9c 远在本卷之前（<0x8b1eea8），不在此文件。
4. **0x9dcda0c UPrimitiveComponent::AzureUpdatePrimitiveLightingAttachmentRoot (172B)** — 已精读。更新图元的光照附件根（角色换挂点后刷新光照绑定），Azure 角色光照系统的一部分。
5. **0x97de624 UWidget::DoTweenerLinearColor (280B)** — 已精读。游戏方给 UWidget 加的 FLinearColor 补间（UI 颜色渐变），若 UI 血条/受击闪白走 UMG，可能相关；非 Spine。
6. **0x97aae48 GetValue<FLinearColor,UObject> (876B)** — 属性路径读 FLinearColor 的通用端（配置→颜色属性的通道）。
7. **0x9763a34 UImage::GetDynamicMaterial (328B)** — UMG→MID 创建点；0x978c50c Execute(972B) 内另有 MID 引用。
8. **0x9dbb70c ULightComponent::UpdateColorAndBrightness / 0x9dbafc4 ComputeLightBrightness** — 引擎灯光颜色链路（角色动态光调节会经过），引擎通用非 Azure。

**重点目标核查（负结论，均有行号证据）**：
- **SetAzureCharColor=0x9dbadd4：不在本文件**。该地址落在 0x9dbac70（GetLightComponentMapBuildData 结束）与 0x9dbafc4（ComputeLightBrightness 开始）之间的反编译空洞中；全文 grep "0x9dbadd4" 0 命中。
- **FAzureMaterialParamSet::ApplyParams=0x97ee7cc：不在本文件**。落在 0x97edbe4（UWrapBox::OnSlotRemoved 结束）与 0x97ef038（FAzureSlateMeshData::OnRelease 开始）之间的空洞；grep "0x97ee7cc" 0 命中。这两个函数应去覆盖 0x97ee000–0x97ef000 与 0x9dbad00–0x9dbaf00 的其它 part 文件查找。
- **spine 顶点色生产端 0x70b25f0：不在本卷**（0x70b25f0 < addr_min 0x8b1eea8）；本卷无任何 spine/VertexColor 符号（关键字 spine=0，grep VertexColor 0 命中）。
- **UMID 参数族 0xa0e5800：不在本卷**（> addr_max 0x9deef0c）。本卷仅有 UMaterialInstanceDynamic::Create 的调用点（0x9763a34 等），无 MID 参数设置族。
- **CharacterLightParams=0xa3e9720、AzureOutlineColor_WidthInA=0x6fccf9c：均不在本卷地址域**。
- 本卷与"pulse 闪光"（正弦原色↔纯黑切换）最接近的线索只有 FAzureMaterialParamSet 三组 4 字节数组的 float 存储布局（可被动画驱动的 UScriptStruct）与 UWidget::DoTweenerLinearColor；值流两端的填充端与消费端（ApplyParams）都不在本卷，需要沿 0x9829938 的交叉引用（FUN_071858f0/0718579c/07185648 属于另一地址段 0x0718xxxx，明显是别的翻译单元）继续追。
