## 战斗渲染相关性
结论：**本文件无 Spine 渲染函数**（`grep -i spine` 在 8MB 全文零命中；地址域 0x95685a0-0xa2b6ddc 与 spine 顶点色生产端 0x70b25f0 相距甚远），也无顶点色生产端。但存在以下与"每帧写材质参数 Value R/G"直接相关的机制与 Azure 游戏层痕迹：

1. **0x958daa0 FDefaultMaterialAccessor::Apply（证据：行 2928-3010 实读）**——`FEvaluatedParameterSectionValues` 的 scalar/vector/color 参数循环逐个调 `UMaterialInstanceDynamic::SetVectorParameterValue`（vector 段显式 `FLinearColor::FLinearColor` 构造后传入）。这是 Sequencer(LayerSequence) 每帧写材质颜色参数的执行终点。若战斗角色的颜色脉冲由 LevelSequence 驱动，调用链尾在此。上游是 0x958dc6c FMovieSceneComponentMaterialSectionTemplate::Evaluate。
2. **0xa0e6ba8 UMaterialInstanceDynamic::K2_InterpolateMaterialInstanceParams（行 183838-184110 实读）**——A→B 材质全参数 lerp：标量走 `SetScalarParameterValueInternal(行183974)`，向量走 `SetVectorParameterValueInternal(行184083)`，`fVar24+(fVar20-fVar24)*param_3` 线性插值。可完成"原色↔目标色"的渐变（非正弦，但可与外部正弦 t 配合）。与兄弟文件 UMID 参数族 0xa0e5800 区同属 0xa0exxxx 材质参数代码段。
3. **0xa129b5c FUniformExpressionSet::FillUniformBuffer（行 190568 实读）**——渲染线程每帧把 uniform 表达式值填入 uniform 缓冲（含参数集合/外部纹理/RVT）。与兄弟文件发现的 Uniform 覆盖 0xa122df0/0xa123078 同处 0xa12xxxx 区，地址连续。
4. **Azure 游戏层实体簇（全部实读核对）**：
   - 0x969bd08 Z_Construct_UClass_UAzureMovieSceneEventTrack_NoRegister——`UAzureMovieSceneEventTrack`（UMovieSceneEventTrack 子类，0xc0），Azure 层用 Sequencer 事件轨驱动游戏逻辑。
   - 0x98319cc StaticStruct&lt;FAzureMaterialParamSet&gt;——0xf0 字节的 Azure 材质参数集结构（含完整反射/序列化/网络序列化 TCppStructOps 簇 @0x67485-67630 行）。**该结构本身就是"Azure 实体→材质参数"的数据载体候选**；其字段布局需在别的 part 中由 Z_Construct_UScriptStruct_FAzureMaterialParamSet_Statics 属性表进一步确认（本文件只引其构造函数指针）。
   - 0x9829aa8 AddStructReferencedObjectsOrNot&lt;FAzureSlateMeshData&gt;——Azure 的 Slate 网格数据结构（UI 侧实体网格）。
   - 0xa0bd104 UMaterial::IsEnableAzureDepthFade——UMaterial+0x227 bit4 的**新增自定义材质标志**（Azure 深度淡出），证明引擎被 Azure 框架打补丁。
   - 全局变量钩子：`GAzureAllowSwitchVerticalAxis`（0x96d32c8 DrawWindowToTarget_RenderThread 读取，行 35993）；`GAzureInvalidationBoxOptimize_UseFullScreenWrapper`（0x97e5e20 UWidgetComponent::UpdateWidget，行 59774）；`GAzureIsReplaceShadowCenter/GAzureReplaceShadowCenterPos/GAzureReplaceShadowFarSplitDist`（写入端 0x9de34b8 FUN_09de34b8 行 165438-165441，读取端行 164896 FDirectionalLightSceneProxy 路径）——Azure 阴影中心替换。
5. **0x97732c8 UProgressBar::SetPercent（行 47360 实读）**——向 FillMaterial 的 MID 写标量参数 "Progress"：UMG 层"每帧写材质参数"的标准范式（非战斗，但同类模式）。
6. **未发现**：Spine 相关（无）、pulse/flash/blink 关键字（无，仅 PhysX AddImpulse 误匹配）、顶点色生产端（UParticleModuleColorOverLife@0xa21d41c 属粒子生命周期颜色，非角色顶点色）。UMID 参数族写端（SetVectorParameterValueInternal 本体）不在本文件定义（本文件仅 K2_Interpolate 内调用它），与兄弟文件 0xa0e0ffc 一致。
