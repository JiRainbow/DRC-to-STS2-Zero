# part_000059.c 分析

## 概况

- 函数数：5038（与 profile 一致，全量解析自 `// ==== FUNC` 头）。
- 地址域：0x9311cf4 – 0x9e62764（跨度约 11.9MB，但相邻分卷函数交错穿插，域内存在大量不属于本卷的空洞，如 0x9dbadd4）。
- 主要类/域（按 :: 符号频次归纳）：
  - **UE::MovieScene**（2480 处）——Sequencer 实体化求值系统为绝对主体：FSystemInterrogator、TPreAnimatedPropertyStorageImpl、TComponentLock、TAddConditional、TPropertyValueStorage 等；含 UMovieSceneEventTrack / **UAzureMovieSceneEventTrack**（Azure 定制事件轨）及 MovieSceneTracks 类注册（_INIT_800）。
  - **动画**：FAnimNode_Trail（780 处 FAnimNode 族）、UBlendSpaceBase::TickAssetPlayer、UAnimInstance 相关静态注册（AZURE_ANIM_INSTANCE CVar）。
  - **UMG/Slate**：UWidget 族 500 处、/Script/UMG 注册 85 条字符串、TSlateElementPS 着色器排列（168 处，含 USE_SOFTCLIP 软裁剪）、SRetainerWidget::OnPaint。
  - **Audio**（572 处）：AudioMixer 卷积混响（FUniformPartitionConvolution 等）。
  - **地形/植被**：FLandscapeSharedBuffers 索引缓冲、LandscapeLayers PS、grass.* CVar 静态初始化（_INIT_771）、UInteractiveFoliageComponent/UFoliageType。
  - **网格几何**：FMeshDescription / FStaticMeshOperations（RemapPolygonGroups、ConvertToRawMesh 等 57 处）。
  - **灯光**：ULightComponent（ReassignStationaryLightChannels）、FDirectionalLightSceneProxy 阴影初始化、FLightPropagationVolumeSettings、UDecalComponent。
  - **其它**：FMemory 泛型（1881 处符号命中）、UCharacterMovementComponent（147）、FAssetRegistryState、UMediaTexture、FShaderCompilerDefinitions（104）、UCharacterMovementComponent/AActor/FFrame 等 engine 底座。
- 结论：本卷是"引擎杂锦卷"——Sequencer/动画/UMG/音频/地形/网格工具的混合体，不含任何游戏业务渲染本体。

## 战斗渲染相关性

**总结论：本卷不含 Spine/角色颜色脉冲本体，但含 ReplaceDirectionalLight 全局块的一个下游消费点。** 依据如下（全部经 grep 全文验证）：

1. **0x70b25f0 / 0x70b2424 / 0x70c0d30（spine 顶点色生产端/分流器）本体不在本卷**。地址域证明：本卷 addr_min=0x9311cf4，三者均在 0x70xxxxx 区间，地址域不覆盖；全文 grep `0x70b25f0|0x70b2424|0x70c0d30` 零命中。
2. **0x6e2b57c（ReplaceDirectionalLight exec thunk）的调用者不在本卷**：全文 grep `6e2b57c` 零命中；亦无 UAzureSceneImage/ReplaceDirectionalLight 符号。
3. **SetAzureCharColor=0x9dbadd4 不在本卷**：位于 0x9db996c(CheckStillInWorld 结束)与 0x9dbbb9c(SetUseTemperature)之间的空洞（相邻分卷函数穿插区），FUNC 头表无此项；全文 grep `9dbadd4` 零命中——因此其调用者与"AzureCharColor 值来源"在本卷内均不可见。UMID 参数族 0xa0e5800 与 ApplyParams=0x97ee7cc 本体同样不在（前者超域，后者无 FUNC 头）。
4. **★ 有效发现——ReplaceDirectionalLight 全局块的消费点：0x9ddbdf0** `FDirectionalLightSceneProxy::GetViewDependentWholeSceneProjectedShadowInitializer`（size=1280，行 213847）。证据（行 213922–213975）：`if (GAzureReplaceLightingParams._1_1_ == '\0')` 走原生光方向；否则光方向向量取自 **DAT_0c6196c0（打包 xy）与 DAT_0c6196c8（z）**，归一化后构造阴影朝向矩阵写入 FWholeSceneProjectedShadowInitializer。即 ReplaceDirectionalLight（exec thunk 0x6e2b57c 写 0x0c6196b0/b8）所在全局块中，**0x0c6196c0/c8 是替换光方向向量，被本卷用于方向光阴影级联朝向**——补全了该链路的渲染下游。本卷内该全局块无其它使用者（grep DAT_0c6196* 全文仅此一处）。
5. **0x9db34b0 AzureSetReplaceShadowAutoCalcCenter**（size=904，行 211632）：写 `GAzureReplaceShadowAutoCalcCenter` 全局布尔（替换阴影自动算中心开关），带游戏/渲染线程检查与渲染命令列队安全下发。与上一条同属 Azure 替换光照(AzureReplace*)系统，为该家族在本卷仅有的两个实体。
6. **0x9e2ca58 USkinnedMeshComponent::SetVertexColorOverride_LinearColor**（size=216，行 219293）：蒙皮网格顶点色覆盖通用 API，FLinearColor→FColor（sRGB=false）后调 SetVertexColorOverride。与 0x70c0d30 顶点色填充调度器属"同机制不同实现"（引擎通用层 vs Azure 定制层），本卷无 Azure 侧填充逻辑。
7. **FAzureMaterialParamSet 仅以结构体拷贝形式出现**：0x9829838 `TCppStructOps<FAzureSlateMeshData>::Copy`（行 112447）逐元素调 `FAzureMaterialParamSet::operator=`（行 112463）——证明 FAzureSlateMeshData（UMG/Slate 网格数据）内嵌 FAzureMaterialParamSet；另有 0x98319c0 该结构体类型 Hash。ApplyParams 本体不在此，无法从本卷读出参数应用顺序。
8. **0x9671338 ~UAzureMovieSceneEventTrack**：Azure 定制 Sequencer 事件轨析构。Sequencer 事件轨是运行期蓝图事件（如 ReplaceDirectionalLight 类调用）的承载通道，但本卷无其 Execute/触发函数，亦无对 0x6e2b57c 的直接调用证据。
9. **Spine 与颜色脉冲：无**。profile keywords spine=0；pulse 唯一命中为 MovieScene Time Signature 的 "Pulse override array" 字符串（行 134588，音乐节拍语义）；USE_SOFTCLIP 属 Slate 软裁剪着色器排列（0x9706598–0x9710a28 的 TSlateElementPS::ModifyCompilationEnvironmentImpl 族），与 Spine 着色器无关。本卷未发现任何 Spine 顶点色生产、SetAzureCharColor 颜色写入、材质参数动画（pulse/正弦插值）类函数。
