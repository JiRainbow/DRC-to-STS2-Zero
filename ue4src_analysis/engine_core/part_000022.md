## 战斗渲染相关性
**结论：无战斗渲染链本体，relevance=engine。** 依据与边界如下：

1. **地址覆盖核查**：已闭合链全部地址——0x70c0d30（顶点色调度器）、0x70b2424/0x70b25f0（Dark/Color 分流与 spine 顶点色生产端）、0x6c363e4/0x6d02438/0x6e8cf4c（ReplaceDirectionalLight 族）、0x9dbadd4（SetAzureCharColor）、0x9110a64（写点）、0x97ee7cc（FAzureMaterialParamSet::ApplyParams）——均落在 0x6exxxxx–0x9dxxxxx 区间，而本卷地址域为 0x72069e0–0x7fd4f6c，**一个都不在内**；0xa0e5800 UMID 参数族区也不在内。
2. **符号引用核查**：全卷 grep `FUN_070c0d30|FUN_070b25f0|FUN_070b2424` 0 命中；`spine` 0 命中；`SetVectorParameterValue|SetScalarParameterValue|UMaterialInstanceDynamic|MaterialParamSet|ReplaceDirectionalLight|UAzureSceneImage|SetAzureCharColor` 0 命中。→ **①调度器上游/slot 标志来源、②Dark 二级 tint 值来源、③AzureCharColor/ReplaceDirectionalLight 色值来源：本卷均无线索**，需回 0x70axxx–0x70cxxxx 邻卷与 0x9dxxxxx/0x6cxxxxx 卷找。
3. **Azure 命名皆为腾讯"Azure"引擎基础设施误报，非角色颜色系统**（逐个已读核实）：
   - 0x79fd084 MallocAzureProtect::FMallocAzureProtect::ValidateHeap（8B stub，堆保护分配器）
   - 0x7a08968 FMallocAzureOverrun::Exec / GetDescriptiveName→"AzureOverrun"（越界防护分配器控制台口）
   - 0x7f0ac94 FSlateInvalidationRoot::PaintFastPath_FixupParentLayerId（参数为 AzureMerged::FSlateInvalidationPaintFastPathContext；Slate 合批优化命名空间）
   - 0x7fada84 FSlateBrush::UpdateRenderingResource 内有 `UAzureAtlasInterface::GetPrivateStaticClass()` 比较——Azure 图集刷子资源接口（UI 侧）
