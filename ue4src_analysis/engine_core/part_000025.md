# part_000025.c 分析

## 概况
- 函数数：3810；地址域：0x7316640 – 0x8814fa4（约 21.6MB 的地址空间）；文件 8.0MB。
- 本卷是**混合底座卷**，按字节占比以 **Slate/UMG UI** 为最大头（12 个最大函数里 9 个是 Slate），其余为几何/网格算法、Niagara-Chaos 粒子数据接口、媒体/音频、Vulkan RHI、压缩/平台杂项。

## 战斗渲染相关性
**结论：无直接相关性。** 依据：
1. **地址域不覆盖**：本卷 0x7316640–0x8814fa4 不含任何已闭合链地址——0x70b25f0 / 0x70b2424 / 0x70c0d30（Spine 顶点色生产/调度）低于本卷下界；0x6e2b57c（ReplaceDirectionalLight thunk）、0x9dbadd4（SetAzureCharColor）、0x9110a64（写点）、0x8efb15c/0x9130678/0x9ddbdf0（全局消费端）高于本卷上界。grep 全部 10 个地址串，0 命中。
2. **本卷 "Azure" 是 UI 子系统**，与 Azure 角色颜色系统同名不同物：
   - UAzureAtlasInterface 0x7fad4b8 + Z_Construct_UClass_UAzureAtlasInterface 0x7ffc36c + StaticClass 0x7ffc48c：SlateCore 的 UI 图集接口类注册，证据是注册命名空间 L"/Script/SlateCore"、L"AzureAtlasInterface"。
   - FSlateBrush::SetAtlasInfo(IAzureAtlasInterface*) 0x7fadd34、AzureFSlateBrushDebuger::OnAdd 0x7fae2b8（证据：函数体仅操作 FSlateBrush+0x58/0x60 资源名并 TSet::Emplace 进调试注册表）。
   - GAzureInvalidationBoxOptimize_DontUpdateListWhenVolatile / _PartiallyUpdateChildOrder：SInvalidationBox 优化 cvar，消费点 0x7f08af0（107372 行）、0x7f8764c（116373 行）、TPanelChildren::Swap 0x7fcf32c 邻域（131102 行）。全部是 UI 失效路径。
3. **顶点色活动仅为 Slate UI 顶点**：AddBorderElement 0x7f66298（FLinearColor::ToFColor → 0x2c 字节 FSlateVertex）、AddInstancedShapedTextElement lambda 0x7f83da4（文字描边 FColor）。无逐顶点 tint 调度、无二级 Dark tint、无 slot 标志逻辑——那些在 0x70bxxxx 卷。
4. **"pulse" 仅音频**：execSetOscPulsewidth 0x78a6d20 / Z_Construct…SetOscPulsewidth 0x78a8860（UModularSynthComponent 振荡器脉宽），非颜色脉冲。
5. **①②③ 专项回复**：① 三目标函数不在本文件（见第 1 条），无法在此精读 Dark tint 来源；② 0x6e2b57c 的调用者/注册点不在本卷（0 命中），本卷也没有 UAzureSceneImage 任何符号；③ AzureCharColor 值来源链（0x9dbadd4/0x9110a64）不在本卷。相邻区提示：0x7fad000–0x7faf000 的 Azure UI 函数与目标链无调用关系，仅供排除。
