## 战斗渲染相关性

**结论：无。** 依据（逐项验证）：

1. **地址域不覆盖**：本卷 0x75d3ddc–0x8507d28。目标链中 0x70b25f0（spine 顶点色生产端）、0x70b2424（分流）、0x70c0d30（顶点色填充调度器）、0x6e2b57c（ReplaceDirectionalLight exec thunk）、0x9dbadd4（SetAzureCharColor）、0x718e77c（DarkenAction 注册）全部低于 addr_min 或不在此区间；0xa0e5800（UMID 参数族）高于 addr_max。**本文件不含这些函数本体。**
2. **无地址引用**：`grep -n -E "70b25f0|70b2424|70c0d30|6e2b57c|9dbadd4|a0e5800|718e77c"` 在全文 0 命中——**没有本卷函数调用 0x6e2b57c 或引用 AzureCharColor 相关闭地址**。
3. **无关键词**：`spine` 0 命中；`SetAzureCharColor`/`ReplaceDirectionalLight`/`DarkColor`/`SetVertexColor` 0 命中；`pulse` 11 处全部为音频（FEpicSynth1/UModularSynth 的 OscPulseWidth、UAudioImpulseResponse），与闪光脉冲无关。
4. **"azure" 的 10 处命中均为腾讯引擎基础设施，与 UAzureSceneImage 无关**（逐条读上下文确认）：
   - `MallocAzureProtect::APCheckAllActiveMemState`（0x79fb288）— 内存溢出保护器；
