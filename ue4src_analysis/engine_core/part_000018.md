## 战斗渲染相关性
**已闭合链路地址在本卷全部零命中（grep 依据）**：`70b25f0`、`6e2b57c`、`8eface8`、`8efb15c`、`9130678`、`9dbadd4`、`97ee7cc`、`a0e5800`、`AzureCharColor` 均无任何匹配。本卷地址域 0x6f5a120–0x8259638 数值上覆盖 0x70b25f0，但函数清单在 0x70b0f24 → 0x70b576c 之间存在空洞，**0x70b25f0 本体不在本文件**（分区交织所致）。

相关但间接的内容（同类/相邻区，均经 Read 取证）：
1. **spine-cpp 颜色动画数据生产端**：0x70eeee4（readAnimation 全内联）——TwoColorTimeline 每帧解析 RGBA+RGBA2 并虚调用 setFrame（time=1.0..5.0f 连续帧）。若角色的黑闪/变色由 Spine 动画时间轴驱动，数据即从此读入；它与 0x70b25f0（顶点色填充，外部卷）同属 spine-cpp 数据层。
2. **0x70b25f0 地址相邻区函数**：0x70b0f24（spine HashMap 插入，0x9e3779b9 哈希）、0x70b576c/0x70b71cc/0x70b7500/0x70b7534/0x70b8f84（spine-cpp 容器与骨架辅助，未逐一精读）。
3. **Spine 材质入口（BP API）**：`AdditiveBlendMaterial`（0x7018b94 SpineSkeletonFastRenderer / 0x70a772c、0x70208f4 附近 USpineWidget/组件）与 `atlasScreenBlendMaterials`（0x701c094、0x70a8554）——Spine 渲染器/控件上可被 BP 换的材质槽，是颜色脉冲若走"换材质"路线的候选注入点；渲染本体不在本卷。
4. **USpineWidget 装配链**：0x70c6c2c SynchronizeProperties→SetSkin/Init/回调注册、0x70c8150 骨架重建、0x70c64b8/0x70c6520 日志。
