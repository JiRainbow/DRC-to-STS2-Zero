## 战斗渲染相关性

**结论：本卷含 0x6e2b57c 本体与 Spine 邻域辅助函数，但不含 Spine 顶点色生产端与任何 pulse/darkColor/AzureCharColor 逻辑。**

1. **0x6e2b57c（ReplaceDirectionalLight UFUNCTION thunk）本体在本卷**（行 108391，524B）。精读证据：FFrame::Step 读参数2 为 FLinearColor（4 个 float：local_48/44/40/3c = R/G/B/A），参数3 为 FVector（local_58/54/50 = 方向），直接尾调 `AzureReplaceDirectionalLight(bool, FLinearColor*, FVector*)`。无静态调用者（全卷对 FUN_06e2b57c 仅定义处 2 次出现），调用方为蓝图 VM 经 natives 表；实现体 0x8eface8 位于 **part_000039.c**（1140B，IsInRenderingThread 检查 + FBaseGraphTask 渲染线程派发）。全局 0x0c6196b0/b8 不在本卷出现。
2. **0x70b25f0 不在本卷**：grep "70b25f0" 全卷 0 次（地址域覆盖但正文无；本体在 part_000009.c / part_000017.c）。**地址近邻在本卷**：前邻 0x70b20f4(812B，FMemory::Free 清理辅助)，后邻 **0x70b6448(1924B，spine .json/skeleton 加载辅助)** —— 若 0x70b25f0 为 Spine 顶点色填充，其同类（SpinePlugin 渲染/数据块 0x70b–0x713）在本卷仅有蓝图 thunk 与加载辅助，无顶点色打包代码（全卷 "darkColor/DarkColor/Tint" 0 次）。
