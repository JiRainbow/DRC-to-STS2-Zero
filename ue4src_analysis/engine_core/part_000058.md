## 战斗渲染相关性

**结论：本文件不包含战斗角色 Spine 颜色脉冲链的任何环节。** 依据：

1. **地址域排除**：文件函数地址域为 0x9188834–0xa3a9bbc，已知链地址 0x6e2b57c（exec ReplaceDirectionalLight thunk）、0x70b1554/0x70b2424/0x70b25f0/0x70c0d30（顶点色分批/调度/填充）、0x9dbadd4（SetAzureCharColor）、0x9110a64（写点）、0x8efb15c/0x9130678（消费端）**全部不在域内**；且全文 grep `sub_(70B25F0|70B2424|70C0D30|70B1554|6E2B57C|9DBADD4|9110A64|8EFB15C|9130678|0C6196B0)` 0 命中 —— 本文件既不定义也不调用它们。
2. **"谁调用 0x6e2b57c"**：本文件无任何引用，答案不在此文件。
3. **"AzureCharColor 值来源"**：全文（不分大小写）grep `AzureCharColor|AzureScene|ReplaceDirectionalLight` 0 命中；`Azure` 仅命中 UMG Slate 侧符号（见下）。
4. **Spine/pulse 排除**：`spine` 仅 `FRadixSortSpineCS`（0xa2 区 GPU radix sort 计算着色器，StaticGetTypeLayout 注册，与 Spine 骨骼动画无关）；`pulse` 仅 `Audio::FImpulseResponse`（卷积混响脉冲响应）与 `ARadialForceActor::FireImpulse`。无贴图原色↔纯黑切换、无正弦颜色调制、无 Dark 二级 tint、无 slot 标志相关代码。

**存在但仅限 UI 侧的 Azure 材质参数底座**（与战斗链同属"Azure"引擎改造，但作用于 Slate/UMG 而非角色）：
