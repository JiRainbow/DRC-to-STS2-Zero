# part_000037.c 分析

## 概况

- 函数数：2971（与 profile 一致），地址域 **0x7fd58bc – 0x86d8904**（ARM64 反编译，含 tpidr_el0 栈保护模式）。
- 本卷是"引擎底座混合卷"，四大块：
  1. **Chaos 物理窄相/查询**（top_symbols 里 Chaos 7503 处）：GJK/EPA 凸形穿透族（`InitializeEPA<float, Chaos::GJKPenetration<...>>` 实例化 163 处、`Invalid tetrahedron encountered in InitializeEPA` 断言 ×10）、`GenericConvexConvexContactPointSwept`、`ConstructConvexConvexOneShotManifold<...>` 模板族、`TBoundingVolume::SweepImp`。
  2. **Voro++（泰森多边形库）**：`voro::voronoicell_base::nplane<...>`、`find_voronoi_cell` ×3、`container_base` —— 供 Chaos 破碎/粒子单元切割用（双精度浮点）。
  3. **Slate UI 框架**：FSlateApplication(33 函数)、SEditableText(28)、FTextLayout(25)、SSlider(20)、SDockTab(18)、FSlateUser(16)、SWindow(15)、SColorGradingPicker/Wheel、SBreadcrumbTrail、FTabManager、SSuggestionTextBox、SWizard 等（桌面风格编辑器 UI 控件全家桶）。
  4. **RHI/Shader 管理底座**：FNullDynamicRHI(13 函数，空 RHI 存根 + LockVertexBuffer 等)、FShaderPipelineCache(11) / FPipelineFileCache（.upipelinecache PSO 缓存）、FShaderParametersMetadata::InitializeLayout、FGenerateMipsVS / FPixelShaderUtils::FRasterizeToRectsVS / ClearResourceCS 族全局 shader 元数据、FShaderCompilerDefinitions、PlatformCreateDynamicRHI（OpenGLDrv 探测）、FImageWriteQueue、jpgd（JPEG 解码器）。
- UClass 注册串可见：`/Script/SlateCore` 下 **AzureAtlasInterface**（见战斗渲染节）、FontBulkData、FontProviderInterface；`/Script/EngineSettings` 下 ConsoleSettings、GameMapsSettings；`/Script/ImageWriteQueue`。
-与本任务目标的地址关系：**本卷 0x7fd58bc 起始，不覆盖 0x70b25f0 / 0x70b2424 / 0x70c0d30（0x70xxxxx 区）与 0x6e2b57c（0x6exxxxx 区），也不含 0x9dbadd4/0x9110a64/0x0c6196b0**（grep 全部 0 命中）。spine 顶点色生产端所在 0x70b 区与本卷无地址相邻关系（中间隔约 0xF0 万字节的其它卷）。

## 字符串要点

- PSO 缓存：命令行开关 `psocache`、`logpso`；文件名格式 `%s_%s.upipelinecache`；日志 "Using %s for material shader code. Total %d unique shaders."（shader code library 统计，属 shader 编译管理而非材质参数）。
- 全局 shader 编译 define：`VALUE_TYPE=float4/uint`、`THREADGROUPSIZE_X=64 / Y=1 / Z=1`、`ClearResource`/`ClearResourceParam`、`DstOffset`/`SrcOffset`（ClearResource/CopyResource 计算 shader 族元数据）。
- Chaos 物理断言：`Invalid tetrahedron encountered in InitializeEPA`（×10 实例）。
- 输入配置：GConfig 节 `UserDefinedChords`、`UserDefinedGestures`、`Content`。
- UClass 注册串：`/Script/SlateCore` → AzureAtlasInterface、FontBulkData、FontProviderInterface；`/Script/EngineSettings` → ConsoleSettings、GameMapsSettings；`/Script/ImageWriteQueue`。
- RHI：`OpenGLDrv` / `OpenGL` 名字探测（PlatformCreateDynamicRHI）。
- 引擎日志分类：`logpso`、`Engine`、`BASE`。
