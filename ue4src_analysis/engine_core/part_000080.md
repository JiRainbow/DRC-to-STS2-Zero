# part_000080.c 分析

## 概况

- **函数数**：4944（FUNC 标记全量解析确认），地址域 **0xa2ed2e8 – 0xb0eda34**，共约 233202 行 / 8MB。
- **性质**：UE4 引擎底座杂合区，不是战斗渲染代码。按符号频次与抽样阅读，内容依次为：
  1. **FMemory（1660 处）** — TSparseArray/TSet/TArray 模板实例化海（文件开头即 `TSparseArray<TSetElement<TTuple<FBodyInstance*,FPhysTarget>>>::Empty`，物理目标稀疏数组）。
  2. **BuildPatchServices / InstallBundleUtil（700+320 处）** — 补丁安装器完整子系统（Compactifier、Prereqs、统计日志）。
  3. **UObject/FFrame/FName/UE4CodeGen_Private** — 反射注册（大量 `Z_Construct_*`、`exec*` BP thunk、`_INIT_*` 静态注册函数）与 APlayerController 族 BP 函数注册（92 处）。
  4. **物理**：physx / physx::shdfnd（330+ 处，文件尾部 0xb08–0xb0e 为 PhysX Dy/Np 区）+ Chaos/GeometryCollection + UClothingAssetCommon 布料。
  5. **AI/导航**：UAISense_Sight（82）、UNavigationSystemV1（79）、Recast 构建函数（rcOffsetPoly 等，0xacd 区）、FNavMeshPath。
  6. **RHI/渲染底座**：OpenGL 着色器编译与程序缓存（FOpenGLProgramBinaryCache）、UpdateTextureShaders 计算着色器（TCopyTexture2DCS / TUpdateTexture2DSubresourceCS / FMoveWholeIndirectionTextureCS）、FViewMatrices、FEngineShowFlags、FSimpleElementDistanceFieldGammaPS（Slate SimpleElement）、FSubsurfaceProfileTexture。
  7. **音频**：USoundWave::Parse、FQuartz 节拍系统结构、FPostProcessSettings 音频外的反射。
  8. **插件边角**：FNativeJSScripting（WebBrowser JS 桥）、**AzureLua 模块 StartupModule**、FWorldDelegates::AzureLevelTile* 委托初始化。
- **主要类**（:: 符号归纳）：UEngine、FEngineShowFlags、FViewMatrices、USkeletalMeshMerge、UClothingAssetCommon、APlayerController(BP 注册)、UAISense_Sight、ANavigationData/FNavMeshPath、BuildPatchServices::*、physx::Dy/physx::shdfnd、FOpenGL*、USoundWave、UTexture2D 族、FShaderCompileUtilities。

## 战斗渲染相关性

**结论：无直接战斗渲染代码，与 Spine 颜色脉冲链路无交集。** 依据（全文件 grep 实测）：

- `azure|spine`（不区分大小写）全文件仅 **14 处**，逐条核对均为外围基础设施，无一处属于 Azure 角色颜色/UAzureSceneImage 渲染路径：
  - 行 41958：`UEngine::Init`(0xa58f7d4) 内检查 `AzureCreateHybridSlateSoundDevice` 工厂指针——**音频**设备选择，非渲染。
  - 行 52328：注册 cvar `azure.ForceUpdateDPIScale`——DPI 缩放。
  - 行 53272–53283：`FWorldDelegates::AzureLevelTileAddedToWorld/RemovedFromWorld` 委托指针初始化——关卡分块加载委托。
  - 行 57142 / **0xa90a86c**：`Z_Construct_UFunction_UPrimitiveComponent_AzureResetILCData`——仅 BP 反射注册样板，实现在别处；"ILC"（Azure 定制光照缓存/插值数据）重置入口的注册痕迹。
  - 行 59704 / **0xa922c10**：`FPostProcessSettings_Statics::NewProp_bOverride_AzureCharacterVirtualLightRotation_SetBit`——FPostProcessSettings 中存在 `bOverride_AzureCharacterVirtualLightRotation` 覆盖位的反射样板。这是**引擎侧证据**：Azure 角色虚拟灯光走 PostProcessSettings 覆盖机制；但本文件只有 SetBit 注册 thunk，无取值/传蓝逻辑。
  - 行 121831 / **0xabd4418**：`AzureLua StartupModule()` 日志——AzureLua 脚本模块启动。
- `pulse` 5 处全部是 `Impulse`（物理冲量）或 `FQuartzPulseOverrideStep`（音频节拍），与颜色脉冲无关。
- `VertexColor` 1075 关键词命中均为模板实例化与 `FStaticMeshVertexColorLODData`（静态网格顶点色 LOD 反射/StructOps，行 68434 起）——静态网格资产序列化，非运行时颜色动画。
- UMID 参数族（0xa0e5800 区）在**本文件地址域之外**（本文件起点 0xa2ed2e8 高于它）；文件内无 `UMaterialInstanceDynamic`/`SetVectorParameterValue`/`SetScalarParameterValue` 符号。
- 两个特别追查目标均不在本文件：
  - **① ReplaceDirectionalLight 调用方**：本文件零处 `ReplaceDirectionalLight`/`SceneImage` 符号，无法提供"谁传蓝色"的线索。
  - **② AzureCharColor/CustomCharacterTexture 值来源**：两符号在本文件零命中，无来源线索。
- 本文件对渲染链唯一有意义的相邻线索：`FPostProcessSettings` 的 `bOverride_AzureCharacterVirtualLightRotation` 反射注册（0xa922c10）与 `UPrimitiveComponent::AzureResetILCData` BP 注册（0xa90a86c），提示追查方向——在含 FPostProcessSettings 主实现与 UPrimitiveComponent exec thunk 实现的文件里找这两个名字；UMID 参数动画应在 0xa0e5800 所在的那个 part 文件。
