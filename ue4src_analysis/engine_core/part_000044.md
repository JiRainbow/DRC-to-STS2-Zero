## 战斗渲染相关性
**结论：本文件基本不承载 Spine 颜色脉冲机制，仅 1 个 Azure 定制函数。**

1. **CreateAzureOutlinePassProcessor = 0x8c2ec04（size 332，唯一强相关）**
   - 证据：实读 136685–136748 行。构造 `FAzureOutlinePassMeshProcessor`（vtable 写入 PTR__FAzureOutlinePassMeshProcessor_0bcb6b38），签名 `(FScene const*, FSceneView const*, FMeshPassDrawListContext*)`。这是 Azure 定制描边（outline）MeshPass 的处理器工厂，属战斗角色描边表现层；但不涉及颜色/脉冲参数。
   - 同族提示：调用方（把该 pass 挂入 FScene 的注册点）不在本文件，可在引用 PTR__FAzureOutlinePassMeshProcessor 的 part 中继续追。

2. **任务链地址零引用（关键否定证据）**
   - 全文 grep（无锚定、含 0x 前缀/裸 hex 两种形式）对 `0x6e2b57c、0x8eface8、0x8f59be8、0x8efb15c、0x9130678、0x9110a64、0x97ee7cc、0x9dbadd4、0xa3e9720、0xa0e5800、0x70b25f0、0x0c6196b0/b8` 共 **0 处匹配**。
   - 字符串 `ReplaceDirectionalLight`/`SetAzureCharColor`/`CharacterLightParam` 0 处匹配（仅命中 UE4 原生 FMobileDirectionalLight*Policy 系列）。
   - **因此：谁调用 0x6e2b57c（ReplaceDirectionalLight 的 UFunction）不在 part_000044.c 中，需到其他 part 文件检索。** 注意各 part 文件地址域交错，本文件名义区间 [0x8424944,0x93116dc] 内的这些地址（如 0x8eface8）实际归属其它 part。
