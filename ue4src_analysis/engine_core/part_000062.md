## 战斗渲染相关性
**直接命中为"无"**：全文件 grep（-i）`charcolor / CharacterLight / IndirectLighting / pulse / spine` 均 0 次；SetAzureCharColor=0x9dbadd4、CharacterLightParams=0xa3e9720、DAT_0c619670(AzureReplaceMovableIndirectLighting)、spine 顶点色生产端 0x70b25f0 均不在本文件地址域或无引用。即 **AzureCharColor 的值源不在本文件**。

**但本文件是"MID 颜色参数落到材质"的渲染管线底座 + Azure 引擎定制层，以下函数与追色链路直接相关**：

1. **0xa0e0cc4 GameThread_UpdateMIParameter<FVectorParameterValue>（824B）**——已读码确认：取 param_2 偏移 0x14–0x1c 的 **FLinearColor 值**，非渲染线程时经 TEnqueueUniqueRenderCommand("SetMIParameterValueName") 投递；若已在渲染线程则直接调 **FMaterialInstanceResource::RenderThread_UpdateParameter<FLinearColor>** + FMaterialRenderProxy::InvalidateUniformExpressionCache + UpdateDeferredCachedUniformExpressions（行209441–209456）。**任何一方（含 AzureCharColor 的写入者）每帧调 SetVectorParameterValue 写 Value R/G，最终必经此处**。UMID 参数族 0xa0e5800 区即本簇。
2. **0xa10e44c ExecuteTask（424B）**——上述渲染命令的 TGraphTask 执行体，与任务给出的渲染线程落点 0xa10e24c 同簇（地址相邻，属同一 SetMIParameterValueName 模板家族）。
3. **0xa10f894 FMaterialInstanceResource::RenderThread_UpdateParameter<URuntimeVirtualTexture_const*>（328B）**——渲染线程命名参数表（0x20 字节/项：ParameterInfo+值）查重/追加模板特化，FLinearColor 特化同族。
4. **0xa0e5ffc UMaterialInstanceDynamic::SetTextureParameterValue（688B）/ 0xa0e54a8 MID 构造（260B）/ 0xa0d95b4 FMaterialInstanceResource::GameThread_SetParent（948B）/ 0xa0e3ba0 CompareValueArraysByExpressionGUID<FVectorParameterValue>（512B）**——MID 参数族完整底座。
5. **0x95ba2e4 FMaterialParameterCollectionExecutionToken::Execute（4200B）**——Sequencer 每帧把颜色/标量关键帧写入 UMaterialParameterCollectionInstance（行29115/29156），是材质颜色脉冲动画的** Sequencer 驱动端**；配套数据端 0x959db80 UMovieSceneColorSection、0x95a2efc FColorParameterNameAndCurves、0x96bf67c Z_Construct_UFunction_…AddColorParameterKey。与已知 FDefaultMaterialAccessor::Apply=0x958daa0（不在本文件）同属 Sequencer 材质链路。
6. **Azure 引擎定制簇（非角色色，但证明 Azure 层深度耦合材质/渲染）**：
   - 0xa0fac20 SetupMaterialEnvironment：`SetDefine(L"USE_AZURE_DEPTH_FADE", GEnableAzureDepthFade && 材质回调)`（行211693）
   - 0xa0f9eac FMaterialResource::IsEnableAzureDepthFade、0xa0dd424 UMaterialInstance::GetAzureDepthFadeDistance（0xe8 偏移自定义属性）
   - 0xa0d8878 UMaterialInterface::ConditionalModifyQualityLevel 使用 AzureGetFallbackQualityLevel::fallbackQualityLevels 表（行208676）
   - 0x973e744 UWidget SetMaterial 分发含 **FAzureSlateMeshData::SetMaterial**（行51418）；0x9821c0c Z_Construct_UScriptStruct_FAzureSlateMeshData（Azure UI 结构已入反射）
   - 0x97dd3d0 UWidget::CheckSlateBrush 检测资源对象 **UAzureAtlasInterface**（行69080）
   - 0x9d10a10/0x9d1cdbc UAzureTexture2DReadable 构造/析构（Azure CPU 可读纹理）
7. **顶点色/Slate 相关**：仅 FSlateVertexDeclaration 引用与 USE_SLATE_INSTANCING 编译 define（0x96dcafc ModifyCompilationEnvironmentImpl 等 3 处）；UMG UnlinkColors/SetBackgroundColor/SetSliderBarColor/SetColorAndOpacity（0x974ae3c、0x977e740、0x98588c8 等）为 UI 颜色 API，与 Spine 角色脉冲无直接证据。顶点色仅 4 处（含 0x9e2c6f0 BeginReleaseOverrideVertexColors，静态网格顶点色释放）。

**结论**：追"AzureCharColor 值从哪来"应去 0x9dbadd4 所在文件与调用方；本文件提供其下游——SetVectorParameterValue→0xa0e0cc4→SetMIParameterValueName→0xa10e44c/RenderThread_UpdateParameter<FLinearColor>→uniform 表达式缓存刷新的完整渲染线程落点，可作断点/交叉引用锚点。
