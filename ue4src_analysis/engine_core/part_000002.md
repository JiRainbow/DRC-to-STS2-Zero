## 战斗渲染相关性

本文件**不含** ApplyParams(0x97ee7cc)、SetAzureCharColor(0x9dbadd4)、FAzureMaterialParamSet、CharacterLightParams、AzureCharColor 的任何引用（grep 全文零命中；0xa0e5800 的 UMID 参数族与 0x70b25f0 的 spine 顶点色生产端也不在本文件地址域内）。但有以下直接相关/邻接证据：

1. **0x6f6784c（size 500）——K2_InterpolateMaterialInstanceParams 的 Lua thunk（已知命中，已核实）**。实读证据（行 192759–192858）：从 Lua 栈取 4 参——`FUN_06566b50(L,1)` 取 MID（null 检查报 "MaterialInstanceDynamic must be non-null"）、参数 2/3 各取一个 UMaterialInstance 并做 `GetPrivateStaticClass` 双重 IsA 校验（UMaterialInstance 层级）、`FUN_0656a2d0(L,4)` 取 float 权重，随后直接调用 `UMaterialInstanceDynamic::K2_InterpolateMaterialInstanceParams(this, pUVar3, pUVar5, (float)dVar2)`（行 192836）。这是 Lua 侧对 MID 参数在两个材质实例间按权重插值的唯一入口，与"贴图原色↔纯黑正弦切换"若由 Lua 驱动参数插值，会经过此 thunk。同区 0x6f5e914–0x6f6fba8 为同类 Lua thunk 海（UMediaPlayer 等亦在其中）。
2. **Spine Lua 属性 thunk 区 0x7017528 / 0x7018938 / 0x7019aec / 0x701b010 / 0x701d544（各 ~220–280B）**：分别校验 SpineSkeletonDataAsset("Bones" 属性懒缓存，实读行 201543–201551)、SpineSkeletonFastRenderer×2、SpineSkeletonRendererComponent×2、SpineWidget/USpineWidget。是战斗角色 Spine 资产从 Lua 侧访问的绑定面。
3. **USpineSkeletonRendererComponent::UpdateMesh 编译于本区**：0x70bd694（40B）为其 clipping 告警日志 thunk（字符串见上，实读行 209427–209437）；紧邻 0x70bb1f0 内含 AActor::GetComponentByClass + FUN_070bb2f4 的组件刷新逻辑（实读行 209400–209424）。UpdateMesh 即 spine 顶点构建/着色的生产环节所在区（0x70b8000–0x70c0000），与 0x70b25f0（顶点色生产端，位于其它 part）地址带紧邻。
4. **spine-cpp 运行时区**：0x7105308（5168B，实读行 213313 确认 spine/Vector.h 内联路径）；0x70c53b8、0x70c4698（USpineStatics::Init）等，0x7100000 段尚有 85 个具名 spine/注册函数。
5. **顶点色语义邻接**：0x69cc2cc `RandomTriCoordVertexColorFiltered` + 0x69ce398 `FDynamicVertexColorFilterData::Init`——Niagara 静态网格 DI 的顶点色过滤采样族（含 0x69b9498 FreezeQuadTree / 0x69ef778 VisitElements<FQuadTreeQueryHelper> 三角查询），证明本文件承载"按顶点色筛选网格表面生成粒子"的能力（战斗命中特效常用），属顶点色数据链的消费者一侧。
6. **间接相关**：0x6a6f2f4 `FNiagaraRendererLights::GenerateDynamicData`（粒子→动态点灯）与 0x71c41b4 PointLightManager 注册同文件；0x6ab282c 系统模拟 tick 受 `sg.EffectsQuality` 降档控制；0x6b62a6c ShowParticleFull 为 UI 侧全屏粒子包装（战斗 UI 点击特效）。
