## 战斗渲染相关性

**结论：本文件不含 Spine、不含材质参数轨道实现、不含 MID 写入端；但包含 LevelSequence 求值后端（材质轨道的执行底座）与 2 个 Azure 定制渲染钩子。** 依据：

1. **无 Spine**：全文 grep `spine`（不区分大小写）0 命中；函数名表 3791 条中 0 命中。与 spine 顶点色生产端 0x70b25f0 无同区函数（本文件地址域 0x8b58ce0 起且无任何 Spine 类符号）。
2. **无 pulse/颜色参数写入端**：`pulse` 0 命中；无 FDefaultMaterialAccessor、无 UMaterialInstanceDynamic::SetVectorParameterValue 族函数；唯一 `TArray<FMaterialParameterInfo>::ResizeGrow`(0x93776e4, 168B) 只是 LandscapeLayer 组件的材质参数信息数组扩容，非求值端。
3. **MovieScene 求值后端（与 FDefaultMaterialAccessor::Apply=0x958daa0 每帧驱动互补的上游）**：
   - `UE::MovieScene::FSequenceUpdater_Hierarchical::Start` = **0x9426e64** (2980B)：序列实例启动求值。
   - `FMovieSceneEvaluationTrack::DefaultEvaluate` = **0x943caf4** (404B)：所有轨道（含材质参数轨道）的求值分发（读代码确认转 EvaluateSwept）。
   - `UE::MovieScene::FEntityManager` 实体系统：`MutateAll` = **0x93e7210** (1660B)、`InstantiateAllocation` = **0x93f90f4** (1240B，读代码确认 AddComponent/CombineComponents)。
   - 混合/通道系统对象：`UMovieSceneBlenderSystem` 析构 **0x93fb304**、`UMovieSceneEvalTimeSystem` 析构 **0x93fb584**、`UMovieSceneEvaluationHookSystem` 析构 **0x93fb60c**（成员含 FMovieSceneEvaluationHookEventContainer 稀疏数组，读代码确认）；`FMovieSceneFloatChannel/BoolChannel/ByteChannel/IntegerChannel/ObjectPathChannel` 析构族 0x93faf88–0x93fb1bc——这些 Channel 即材质参数轨道插值数据的载体类型，但本文件只有其生命周期管理，无求值采样。
   - `FFrameNumberTimeEvaluator::EvaluateTime` = **0x93abd74** (7316B)：Sequencer 时间表达式求值（FExpressionParser）。
   - 若战斗脉冲由 LevelSequence 材质参数轨道驱动，其每帧求值会经过 0x9426e64(Start) → 0x943caf4(DefaultEvaluate) → 实体系统 0x93e7210/0x93f90f4 这条链（本文件），再由其它文件的轨道实现生成 execution token，最终落到 FDefaultMaterialAccessor::Apply(0x958daa0，不在本文件)。
4. **Azure 定制证据（本文件仅有的 Azure 符号）**：
