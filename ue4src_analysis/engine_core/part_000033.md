## 战斗渲染相关性

**有 Azure 管线内容，但无 Spine/pulse/顶点色脉冲**（全文件 grep：spine=0 处，pulse 命中均为物理 Impulse 字符串；关键词统计 material=1160/color=1593 均为 BasePass/半透明等常规渲染参数）。逐条：

1. **0x8c2d5a8 FAzureOutlinePassMeshProcessor::AddMeshBatch (size=508)** — Azure 专属**描边 Pass** 的网格处理器：
   - 过滤条件：`FPrimitiveSceneProxy != 0` 且 `FMeshBatch+0x9c bit3`、`proxy[0x26] byte bit3` 置位、`*(float*)(proxy+0x3c) > 0`（疑为 Bounds.SphereRadius）。
   - 流程：`FMaterialRenderProxy::GetMaterialWithFallback` → `FMaterial::GetRenderingThreadShaderMap` → 虚调用(+0x38 排除某种材质类型、+0x218 判 <2) → **`GetAzureOutlineShaders(material, out VS/PS, *(this+8) 参数)`** → `FMeshMaterialShaderElementData::InitializeMeshMaterialData` → `BuildMeshDrawCommands<TMeshProcessorShaders<FAzureOutlinePassVS, FBaseHS, FBaseDS, FAzureOutlinePassPS, ...>, FAzureOutlineShaderElementData>`。
   - 证据：行 96814–96961 实读。`GetAzureOutlineShaders` 仅被调用（行 96894），**其定义不在本文件**；FAzureOutlinePassVS/PS 与 FAzureOutlineShaderElementData 亦无定义，均为外部符号。描边 Pass 与角色轮廓渲染直接相关，追 Spine/角色描边时应反查 GetAzureOutlineShaders 与该 MeshProcessor 的构造（this+8 处的参数对象）。
2. **0x9207640 FilterPrimitiveForShadows (size=1296)** — Azure 光照替换体系的**阴影消费端**：分支 `GAzureIsReplaceShadowCenter == 0 || GAzureReplaceShadowAutoCalcCenter != 0` 决定阴影图元剔除中心——默认用灯光原点（shadow+0x48 → light+0xbec/bf0），替换时改用全局 **GAzureReplaceShadowCenterPos（FVector，代码可见次分量 DAT_0c618c50，基址约 0x0c618c48–0x0c618c58 区）**。证据：行 139799–139815 实读。该全局区与已知链上的 0x0c6196b0/b8 同属 Azure 替换全局池（相距约 0xa60），说明 AzureReplaceDirectionalLight(0x8eface8) 一族写入的全局不止 0x0c6196b0/b8，还有阴影中心组——**追角色受光/阴影表现时应把 0x0c618c48 区纳入全局清单**。
3. **0x7e60cf0 UObject::ProcessEvent (size=1220)** — 蓝图事件分发内嵌 Azure 调试钩子：`GAzureRuntimeDebugFlag` 置位时按 UFunction 索引查表并输出 FName 日志；另调用外部 `GetAzureDestroyStructFlag()`（行 982/1136 实读）。
4. **0x7e91114 (size=132)** — `GAzureOnObjectCountExceedFuncPtr` 非空则调用（行 5489–5497 实读）：UObject 数量超限的 Azure 引擎改造回调，与渲染无关但属 Azure 定制面。
5. **无** Spine/材质参数动画/顶点色/颜色脉冲函数：本文件不含 FAzureMaterialParamSet、SetAzureCharColor、UMID 参数族（0xa0e5800 区在地址域外）；SetParameters 族 22 个全部是 UE 原生管线着色器（距离场阴影/半透明光照注入/体积云等），与 Azure 颜色系统无交集。
