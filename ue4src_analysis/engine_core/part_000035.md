# part_000035.c 分析

## 概况
- 函数数：2558（profile 与 `// ==== FUNC` 标记实测一致）；地址域 `0x7f29284 – 0x87f80cc`（约 8.9MB 地址跨度）。
- 模块定性：**引擎底座大杂烩卷**，与战斗渲染无直接关系。四块内容按地址域分布：
  1. **SlateCore/Slate UI（0x7f29284–0x83b 区域主体）**：复合字体缓存（TSet<FCompositeFont*, FCachedCompositeFontData>::Rehash 族）、FSlateElementBatcher（AddBoxElement 顶点批生成）、FSlateApplication（指针事件路由）、SDockTab/SDockingTabStack/FTabManager（编辑器式停靠布局）、FInputBindingManager/FUICommandInfo、SColorPicker（颜色选择器 UI）、FTextLayout/FPlainTextLayoutMarshaller（文本排版）、STileView 列表视图；含 7 个 `_INIT_*` 静态初始化器（SlateCore 反射注册 + 字体渲染 CVar 注册）。符号数 Slate 84+、SDock 22、FUICommand 6。
  2. **RenderCore/着色器基础设施（0x84d–0x84f 区）**：FShaderPipelineCache::Close、FMemcpyBufferCS/FScatterCopyCS（GPU memcpy/scatter compute shader，ModifyCompilationEnvironmentImpl 设置 FLOAT4_BUFFER/UINT4_ALIGNED/FLOAT4_TEXTURE 宏）、FGlobalShader 参数绑定。Shader 族 43 个函数。
  3. **Chaos 物理（0x85359f0–0x87f80cc 尾部）**：GJK/EPA 窄相（InitializeEPA 23 处、GJKPenetration 22、GJKRaycast2 大量模板实例化、UpdateGenericConvexConvexConstraintHelper）、TImplicitObjectScaled/Instanced<Convex/Sphere/Box/Capsule> 碰撞。Chaos 族 150 个函数。
  4. **voro++（0x84fcb9c–0x855 区）**：voronoicell_base::nplane / compute_cell（Voronoi 胞元计算，配粒子/破碎类玩法用的第三方库）。
- 另有大量模板/反射样板：operator() 80、ExecuteIfSafe 36、delegate 析构 ~TBaseSPMethodDelegateInstance 36、TCppStructOps/StaticStruct/StaticClass 反射 thunk 群（0x7ffc–0x800、0x84f 区）、FMemory 1203 符号引用（Realloc/Free 高频出现，非独立模块）。
- 主要类（:: 归纳）：Chaos::Collisions、Chaos::TImplicitObject*、voro::voronoicell_base、FSlateElementBatcher、FSlateApplication、SDockTab、FTabManager、FInputBindingManager、SColorPicker、FTextLayout、FShaderPipelineCache、FMemcpyBufferCS、UObject/UScriptStruct 反射族。

- `/Script/SlateCore` x102、`/Script/Slate` x13、`/Script/EngineSettings` x25、`/Script/MaterialShaderQualitySettings` x9、`/Script/DeveloperSettings` x4 —— 本卷是 SlateCore + 引擎设置 + 材质着色器质量设置**反射注册**聚集地（注意 MaterialShaderQualitySettings 只是设置类注册，不含材质参数动画逻辑）。

- `AtlasmapInfo` x4、`Typeface`/`FontData`/`FontBulkData` —— Slate 字体图集/字体资产反射类型。
- UI 样式串族：WindowStyle/ScrollBoxStyle/HeaderRowStyle/SplitterStyle/VolumeControlStyle 等 —— Slate 控件样式结构体注册。
- 全卷 **无** spine/skeleton/fight 字符串；pulse 0 命中。

## 战斗渲染相关性
**结论：无战斗渲染内容，但有 2 个易混淆的同名"Azure"线索，特此记录排除依据。**

1. 目标链各地址（0x6e2b57c、0x70b25f0、0x70b2424、0x70c0d30、0x9dbadd4、0x9110a64、0xa0e5800 区、0x8efb15c/0x9130678/0x9ddbdf0）**全部落在本卷地址域 0x7f29284–0x87f80cc 之外**；对全部 10 个地址做全文 grep 均为 0 命中；`SetAzureCharColor`/`AzureSceneImage`/`AzureCharColor`/`ReplaceDirectionalLight` 符号与字符串 0 命中。→ ①②③三个特别目标（0x70b25f0 精读、0x6e2b57c 调用方、AzureCharColor 值来源）均不在本文件，需到 0x6exxxxx/0x70xxxxx/0x9xxxxxx 所在卷查找。
2. **易混淆点 A——"Azure" Slate 分支**：本卷存在的 Azure 前缀符号全部属于腾讯对 **Slate UI/字体子系统**的内部改造，与战斗角色 AzureSceneImage 无关：
