## 战斗渲染相关性
**结论：Spine 颜色脉冲生产端不在本卷，但本卷含 Azure UMG/Slate 渲染消费端的同邻区函数，且直接覆盖已知锚点 0x97ee7cc 的代码邻域。**

1. **锚点核实（grep 计数均为 0）**：`0x70b25f0`（spine 顶点色填充，地址在 0x936db50 之前，不属本卷）、`0x6e2b57c`（蓝图 UFUNCTION，无任何引用→其调用者不在本文件）、`SetAzureCharColor/0x9dbadd4`、`ApplyParams/0x97ee7cc`（本体在其它卷，尽管地址落在本卷区间内——切卷按 obj 分组）、`0x8eface8/0x9130678/0x7104178/0xa0e5800`、字符串 `spine/darkcolor/EnableDarkColor`。本卷 **无法** 回答"谁调用 0x6e2b57c"与"darkColor RGB787 打包本体"两问。
2. **0x97ee7cc (FAzureMaterialParamSet::ApplyParams) 同邻区函数（0x97c0000–0x9840000，Azure UMG 定制代码带）**：
   - `0x97ee7cc` 前紧邻 `0x97ef090 FAzureSlateMeshData::SetMaterial`（相距 0x8c4）：实读确认仅接受 `UMaterialInstanceDynamic`，MID 存弱指针 +0x100、非 MID 存裸指针 +0x8 —— 佐证 Azure 材质参数族面向 MID 实例（与 UMID 参数族 0xa0e5800 的机制一致）。
   - `0x97ef15c USlateVectorArtData::ConvertToMaterialInstanceDynamic`、`0x97ef2ac SMeshWidget::AddMesh`（FSlateVertex 顶点缓冲+索引构建）：Slate 自定义网格渲染通路，若战斗 UI 内嵌角色网格（如 Spine 转 Slate mesh）走此路径。
   - `0x97e0820 DoTweenerFunctionInternal<FLinearColor>`、`0x97df794 DoTweenerFunctionFloat`：UWidget 上的 Azure 定制 tween，FLinearColor 插值后按属性路径写回——UI 侧颜色动画原语。
   - `0x9831918 FAzureMaterialParamSet::StaticStruct`：结构体 0xf0 字节注册于 /Script/UMG；`0x97c3e40 UWidget::PrivateAllocateWidget` 引用全局 `GAzureCheckUpdateFlagsBeforeModify`。
3. **Azure 全局材质/质量函数（0x9dd 区，与 0x9dbadd4 同为组件侧邻区）**：
