## 战斗渲染相关性

本卷**不含** Spine 顶点色生产端本体：0x70b25f0 与 0x7104178(spine.EnableDarkColorRGB787) 的函数头及引用均不在本文件（地址域内空白，属邻卷）；全文无 darkColor/RGB787 字符串、无 ×255.0 颜色字节打包代码。也未发现 0x6e2b57c 的任何引用。相关项逐个列出：

1. **0x7019890 / 0x701b4c8 / 0x7020ed8 / 0x701c54c**（USpineSkeletonFastRenderer 材质绑定）：`atlasScreenBlendMaterials`、`MultiplyBlendMaterial`、`ScreenBlendMaterial`、`TextureParameterName` 属性 BP getter。证据：FUN_06566b50 取参数后 assert "SpineSkeletonFastRenderer must be non-null"，再以 FUN_0712f130()（=USpineSkeletonFastRenderer::StaticClass，见 0x712f130 注册）解析 FName。→ Spine 角色用什么材质/混合模式画（角色受击闪色若走材质替换，入口属性在此层）。
2. **0x70ad574**（USpineWidget）：`TextureParameterName` getter，StaticClass=FUN_07132500（SpineWidget 注册见 15305 行，类尺寸 0x770）。→ UMG 内嵌 Spine 的图集纹理参数名。
3. **0x712f130 / 0x71291f8 / 0x7129380 / 0x712f754**：Spine 四件套 UClass 注册本体（FastRenderer 类尺寸 0x7f0，字段区含材质数组与渲染状态）。
4. **0x71be190**：UMaterialParameterCollectionInstance::SetScalarParameterValue 调用者（按名查集合→按 World 取实例→设标量）。→ 材质参数集合动画的底层通道之一（与 UMID=0xa0e5800 族互补；本卷地址区不含 0xa0e5800）。
5. **0x71612ac / 0x7161890 / 0x714e3d8**：UPointLightCtrlAction 的 `colorParamType`/`colorCurve`/GetPosWrapperData thunk —— 技能时间轴点光颜色控制动作（与 AzureReplaceDirectionalLight=0x8eface8 链同类：灯光颜色驱动，本卷只有 BP 层）。
6. **0x7146d38**：UDarkenAction.`maxDarkenAlpha`（技能压黑）；**0x7163a10 等**：UPPMatCommonAction.`matType`/`fadeInDuration`（后处理材质动作，`TextureParameterName` 亦出现于该动作属性集，见 939/9125 行两处；技能闪光/pulse 若走后处理材质，BP 入口属性在本卷）。
7. **0x7157710**：PlayFxAction.`followSpineTargetId` thunk —— FX 跟随 Spine 目标的绑定属性（技能特效挂接 Spine 角色的证据）。
8. **0x7088bd4 / 0x7087fac**：Azure Slate 侧 UUIParticleEmitter 资源释放与 GAzureInSlateTickApplication / GAzureCheckUpdateFlagsBeforeModify 全局守卫（Azure UI 粒子底座）。

结论：本卷是 Spine 的 **UObject/BP 接口层与 spine-cpp 数据结构层**，不是顶点填充/着色层。颜色脉冲主链（0x70b25f0 顶点色打包、AzureCharColor 值来源、0x6e2b57c 调用者）均需在邻卷（0x6e2b57c 属 0x6e 区、0x8e-0x9d 区消费端、0xa0e5800 UMID 族）继续追；本卷可确认的是渲染材质绑定属性名（blend 材质数组 + TextureParameterName）与技能侧灯光/后处理颜色动作的 BP 入口。
