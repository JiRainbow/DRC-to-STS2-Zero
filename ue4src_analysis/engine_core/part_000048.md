## 5. 移植提示

1. 角色染色若走"灯光"而非"顶点色"，目标引擎需在光 proxy 上支持**双颜色槽**（普通 Color + CharColor），对应本文件 0x9110a64 的两次 Set 调用模式。
2. 移动前向光照 uniform 布局由 `LOCAL_LIGHT_DATA_STRIDE=6`(vec4)、`MAX_DYNAMIC_POINT_LIGHTS` 等宏决定（0x8c7d898 及同族），1:1 移植光照需对齐这些 stride。
