## 战斗渲染相关性

**总体：本文件没有 Spine 符号/字符串（spine 关键词 0 命中），也没有颜色脉冲逻辑本体；但它包含战斗渲染链路的若干入口/底座，且证实了兄弟文件提出的"角色虚拟光照"视图 uniform 扩展。** 逐项：

1. **CharacterVirtualLightDirection（角色虚拟光方向，自定义 view uniform 成员）— 0xa3e9590（size 200，L2468）**
   `FViewUniformShaderParameters::zzAppendMemberGetPrev` 反射 thunk，写入成员名 `L"CharacterVirtualLightDirection"`、偏移 **0xe80**、类型 3 分量浮点（L2491-2496 为直接证据）。**兄弟档案给出的 0xa3e9658 / 0xa3edb18 两个"角色光照通道"地址恰好落在本文件这组 FViewUniformShaderParameters 成员 thunk 簇内**（0xa3e9658 = 该 thunk 结束处，0xa3edb18 = 0xa3ed730 thunk 与下一 thunk 0xa3ede38 之间的缝隙）。结论：该簇是视图级 uniform 的成员元数据注册，说明本包 UE4 在 ViewUniformShaderParameters 里追加了"角色虚拟光"成员（方向 + 大概率还有颜色/强度成员在兄弟文件的同族 thunk 中）——这正是角色受自定义光照（如受击提亮/纯色化）的底座之一。
2. **UMaterialInstanceDynamic::execSetVectorParameterValueByInfo — 0xa877e5c（size 276，L115516）**
   蓝图原生入口"Set Vector Parameter Value by Info"：从 FFrame 逐参数 StepExplicitProperty 读出参数 info 与 **FLinearColor 值**（4 个 undefined4，L115529-115532）后调用 `SetVectorParameterValueByInfo`（真身在别处）。配套注册 `Z_Construct_UFunction_UMaterialInstanceDynamic_SetVectorParameterValue` 0xa878e74、`UMaterialInstanceDynamic::StaticClass` 0xa878834（L115596 注册名）。**这是"每帧写 Value R/G"候选的脚本侧入口；若战斗层用蓝图设置 MID 颜色，必经此 thunk。** 实际实现与调用方不在本文件。
3. **顶点色缓冲生产端 — 0xa44b130（GenerateLODModel，L10317 构造 FColorVertexBuffer）与 0xa4d1524（InitFromDynamicVertex，L20019 FColorVertexBuffer::Init、L20039 默认色 0x01010101×4）**
   两处都是顶点色（Vertex Color）基础设施：前者在运行时骨骼网格 LOD 合并时生成 FColorVertexBuffer，后者为程序化网格/编辑器 gizmo 构建含顶点色的静态顶点缓冲。若战斗角色的"黑白脉冲"走 VertexColor 表达式，这两处是本文件内的顶点色数据来源（均为数据构建，无逐帧游戏逻辑）。
4. **USkinnedMeshComponent::execClearVertexColorOverride — 0xa947790（L134472，调 ClearVertexColorOverride(LODIndex)）+ 注册器 0xa9486a8**
   证明本包蒙皮网格组件带 **顶点色覆盖（VertexColorOverride）** 机制（Set/Get 部分应在兄弟文件）。这与 spine 顶点色生产端（0x70b25f0，兄弟发现）在机制上同族：运行时可整体覆盖网格顶点色。
5. **UMaterialExpressionVertexColor — 0xa86e24c（InternalConstructor）/0xa86e31c（构造，L114725-114742）**
   仅 codegen/构造，无逻辑；表明顶点色材质表达式类在本包注册。
6. **UWorld::GetParameterCollectionInstance — 0xa63ca00（L53806）+ SetupParameterCollectionInstances 调用点 L54008**
   材质参数集合（MPC）在世界侧的实例查找/初始化，与兄弟文件 MPC 更新（0xa12dffc）同链路；本文件只有查询，无写值。
7. **颜色曲线（LinearColor）脚本入口 — FSlateGameResources::GetCurveLinearColor 0xa491e84；UCurveLinearColorAtlas::execGetLinearColorValue 0xa70d1bc（L83371）；StaticRegisterNativesUCurveLinearColorAtlas 0xa70da24**
   LinearColor 曲线取值入口（UI/Slate 资源侧），可用于驱动颜色动画，但本文件内无战斗调用方。
8. **UCanvas/UKismetMaterialLibrary::execCreateDynamicMaterialInstance — 0xa71a7dc / 0xa7aae38**
   运行时创建 MID 的 BP 入口（战斗特效/角色材质动态化的前置步骤）。
9. **无脉冲闪光实现**：`pulse`/`Flash`/`Tint`（后者仅 PostProcessSettings codegen）在本文件均无颜色脉冲相关函数。**无 Azure 实体/战斗系统函数簇**：本文件的 Azure 全部是流送/粒子 CVar 调参（见字符串要点）。兄弟档案的"内嵌 Lua VM=0xabd1bb0"在本文件对应 0xabd182c–0xabd443c 的**反编译空档**（InteractiveToolsFramework 输入行为/gizmo 区域之间）；该空档前的 FUN_0abd15f0（0xabd15f0，size 572）是带类型标签的值比较/哈希表查串例程，不是 Lua。
