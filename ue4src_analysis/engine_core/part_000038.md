## 战斗渲染相关性
**结论：无直接相关。** 逐项依据：

1. **目标函数本体均不在本卷**：0x70b25f0（spine 顶点色生产端）、0x70b2424、0x70c0d30（顶点色填充调度器）位于 0x70xxxxx 段，本卷地址域 0x80a71dc–0x8b1de2c 完全不覆盖，无法精读。
2. **已知链地址在本卷零引用**：grep `6e2b57c|70b25f0|70b2424|70c0d30|9dbadd4|9110a64|0c6196` 全文 0 命中 —— ②"谁调用 0x6e2b57c"在本卷无答案。
3. **关键词零命中**：`spine=0、pulse=0、VertexColor=0`（全文计数）；`AzureCharColor` 无任何出现 —— ③"AzureCharColor 的值来源"与本卷无关。
4. **唯一 Azure 痕迹**：0x84ae548（424B）在渲染命令任务析构收尾中执行 `GetImmediateCommandList_ForRenderCommand(); GAzureFlushShaderCacheFlag = 1;`。交叉引用：part_000043.c:15625/15631 同样写 1，**消费端在 part_000040.c:35259（读后清零）**。该旗标语义是"Azure 着色器缓存刷新请求"，属 shader 编译缓存运维，不涉及角色颜色/脉冲。
5. **防混淆陷阱**：0x84b25f0 = `~FNullColorVertexBuffer`（RHI 全局空顶点色缓冲析构，配套 0x84b2540 ReleaseRHI），与追查目标 0x70b25f0 **地址数字形似但完全无关**。FNullColorVertexBuffer 是 UE 顶点色声明缺失时的全白 fallback 资源，属 RHI 底座。
6. **颜色类符号全部是编辑器 UI**：FLinearColor 116 处集中在 SColorPicker / SColorGradingPicker / SThemeColorBlocksBar(0x835f770) / SListView<FColorTheme>(0x839e3ac) / FColorDragDrop —— Slate 编辑器取色器，非运行时战斗渲染。
7. `FBlackVolumeTexture::InitRHI(0x84b5f0c)` 的全黑 3D 纹理是采样 fallback 资源（GSupportsTexture3D 缺失时占位），与"贴图原色↔纯黑正弦切换"机制无运行时调用关系。
