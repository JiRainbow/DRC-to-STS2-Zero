- 函数数：4097；地址域 0x70c1a60 – 0x7f28688；约 8.0MB、23.2 万行（Ghidra 输出，`// ==== FUNC addr= name= size=` 头）。

## 战斗渲染相关性

**总判断：本文件不含 0x70c0d30 调度器的上游调用方，也不含 Dark 通道/AzureCharColor 的值来源。** 依据：对 `70c0d30`、`70b2424`、`70b25f0`、`9dbadd4`(SetAzureCharColor)、`97ee7cc`(ApplyParams)、`a0e5800`(UMID 参数族)、`6e2b57c`(exec thunk)、`c6196b0`(全局) 逐一 grep 计数均为 **0**——本文件（0x70c1a60 起）与调度器（0x70b2xxx/0x70c0xxx）地址相邻，但相邻区段是 spine-cpp 资产装载代码而非渲染填充代码；战斗角色 Spine 顶点色链的上游应在**前一个分区文件（覆盖 0x70b2xxx 段）**内继续找。本文件对战斗渲染的价值在 Spine 材质链的"资源与 UI 侧"：

- **0x70c46bc**（Spine UI 材质缓存初始化）★：加载 4 种混合模式 UI 材质并 RootSet 驻留。证据：L286-316 四条 StaticLoadObject + 材质路径字符串；L317-411 读 ObjectIndex(+0xc) → GUObjectArray(DAT_0c4c3a08/DAT_0c4c3a1c) → ExclusiveMonitorPass 原子置 0x40000000(RootSet)。这四个全局 DAT_0c37e5e0/e8/f0/f8 是 UI Spine 渲染的基材质单例——与战斗角色材质链（AzureMaterialParamSet）平行的另一条 Spine 材质供给线，追 Dark/脉冲时可用于对照"基材质如何被选混合模式"。
- **0x70cd60c**（Spine UI 控件逐 slot 材质同步）★：本文件最核心的 Spine 渲染函数。证据：L942 FName("RenderOpacity")；L947-989 控件 +0x1e8..0x1f4 四 float 钳制 [0,1] 后写渲染态 +0x100..+0x10c（RGBA 语义）；L992-1047 slot 计数变化时清空 4 组缓存；L1066-1074/1103-1110 `UMaterialInstanceDynamic::Create` + `SetTextureParameterValue`(纹理名 +0x1d8、哈希 +0x1e0、slot 纹理值) + `SetScalarParameterValue`；vcall +0x440/+0x410 缓存失效比对。**它证明 UI Spine 的 tint 走 MID 动态参数而非顶点色**，与战斗角色的 0x70c0d30 顶点色填充（Color+Dark 二级 tint）是两套机制；若要找 UI 侧"颜色来源"，控件 +0x1e8 起的 FLinearColor 即是（本文件内无写入方，写者在别处）。
- **0x70fece4**（SkeletonBinary 读取）、**0x7109bfc**（SkeletonJson 构造）、**0x70e4508**（PointAttachment 拷贝）、**0x7104a44**（SkeletonData 构造）：Spine 资产装载链，决定 slot/attachment 数据布局（与 0x70c0d30 按 slot 分流的输入数据结构同源），但不做颜色运算。
- **execUpdateInstanceColor=0x724b2ec** 属 `UPaperGroupedSpriteComponent`（L27202-27206 注释证实），**不是** Spine；UPaperSpriteComponent::execSetSpriteColor / UPaperTileMapComponent::execSetTileMapColor 同为 Paper2D 反射 thunk。与 Spine 颜色无直接关系，仅名称易混淆，特此排除。
- 0x71d4ff8 的 "TransitionColor"（AVG 转场颜色）与 0x7e28748 的 "Color"/"LinearColor" FName 注册：非战斗，列出仅供排查命名碰撞。
- 全文无 "pulse"、无 VertexColor 字面量；无 Azure 角色颜色写入函数。UMID 参数族（0xa0e5800 区）同类/相邻函数：**本文件没有**——0x70cd60c 对 UMaterialInstanceDynamic 的调用均为符号化调用（Create/SetTextureParameterValue/SetScalarParameterValue），其实现体不在本文件地址域。
