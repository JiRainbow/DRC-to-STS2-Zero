## 战斗渲染相关性
结论：**本文件不含 Spine 脉冲渲染机制本体**（spine 0 命中；"pulse" 仅命中 FQuartzPulseOverrideStep 音频节拍与物理 Impulse，与渲染无关；无 SetVectorParameterValue/GameThread_UpdateMIParameter）。但包含与已知 MID 颜色参数链**同一地址邻域的查询端基座**，证据如下：

1. **UMaterialInstance/UMaterialInterface 参数基座（0xa0e2a74 – 0xa0e9770，与兄弟文件 0xa0e0ffc SetVectorParameterValueInternal、0xa10de88/0xa10f328 下发链同区）**：
   - `UMaterialInstance::GetBasePropertyOverridesHash` = **0xa0e2a74** (1624B)：MID 基础属性覆盖 SHA 哈希。

   - `GetVectorCurveParameterValue` = 0xa0e8bb8、`GetTextureParameterValue` = 0xa0e8bd0、`GetParameterInfo` = 0xa0e85ec、`GetRefractionSettings` = 0xa0e8be8、`GetBlendMode` = 0xa0e8ccc。
   - `FMaterial::*_GameThread` 特性位查询 = 0xa0e8500/0xa0e8520/0xa0e8540/0xa0e85a0。
   - `_INIT_936` = **0xa0e9770**：该材质 TU 静态初始化，注册 `FMaterialShaderMap::GIdToMaterialShaderMap` 全局表 + 互斥锁（shader map ↔ material 关联的基础设施）。
   - 追链路时的路标意义：0xa0e0000–0xa0ea000 整带为 UMaterialInstance/UMaterialInterface/FMaterialShaderMap 参数 TU，与 Uniform 覆盖对 0xa122df0/0xa123078、MPC 0xa12dffc 同属材质参数地址带，本文件占据其查询端。
2. **顶点色/颜色传参侧**（无 Spine，间接相关）：
