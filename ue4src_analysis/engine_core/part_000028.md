## 战斗渲染相关性

**无。** 依据：

1. **地址域排除**：本卷区间 [0x7405194, 0x8c5defc]。已闭合链上的目标全部不在本卷——
   - `0x6e2b57c`（ReplaceDirectionalLight exec thunk）、`0x70b2424`、`0x70b25f0`（spine 顶点色生产端）、`0x70c0d30`（顶点色填充调度器）：均 **< 0x7405194**，不在本文件，无法精读其本体；
   - `0x8efb15c`、`0x9130678`、`0x9110a64`（SetAzureCharColor 写点）、`0x9dbadd4`（SetAzureCharColor）、`0x9ddbdf0`、`0xa0e5800`（UMID 参数族）：均 **> 0x8c5defc**，不在本文件。
2. **关键词零命中**（全文件大小写不敏感 grep）：`spine`=0、`pulse`=0、`fight`=0、`UMaterialInstanceDynamic`=0；`Set{Vector,Scalar,Texture}ParameterValue` 仅误命中 `FConfigCacheIni::SetVector2D`(0x7b3fcfc，ini 配置写浮点向量)，与材质参数动画无关。
3. **颜色类函数全部是编辑器 UI**：所有 FLinearColor/FColor 符号注释命中均属 Slate ColorPicker 族（SColorPicker::MakeColorPreviewBox=0x8344980、SColorPicker::Construct=0x8338f54、HandleThemeBarColorSelected、SColorSpectrum/SColorWheel/SColorGradingPicker/SThemeColorBlocksBar/SListView<FColorTheme> 族），是编辑器取色工具，与运行时战斗渲染、顶点色生产、脉冲闪光无调用关系证据。
4. **本卷 "Azure" 是引擎定制层标记而非 AzureCharColor 体系**（对追链有辅助价值）：
   - `_INIT_456`=0x7c0cdbc：注册 `FAzureCustomVersion`，GUID `0xa85c4438b8f7d6e1 / 0xc50436379c7a9352`，版本名 **"AzureVer"、ID 0x3ec** —— 游戏定制包序列化自定义版本，可作为判定"定制引擎改动"的锚点；
   - `FDynamicRHI::RHIFlushCompiledShaderCache`=0x83cf97c（16 字节）：`GAzureIsInFlushShaderCacheState = 0;` —— 着色器缓存 flush 状态旗（"Azure"=定制着色器管线命名空间）；
   - `SScrollBox::ScrollBar_OnUserScrolled`=0x8252710（496 字节，精读）：滚动回调尾部检查 `GAzureCheckUpdateFlagsBeforeModify`，为真才执行 `FWidgetProxyHandle::UpdateWidgetFlags` + `SWidget::Invalidate` —— 定制版 Slate 控件失效守卫。若后续需要排查 Slate 层刷新抑制（例如 UI 颜色不刷新类 bug），该全局是引擎层入口。
5. 唯一与"粒子/VFX"相关的是 `FNiagaraDataInterfaceParametersCS_ChaosDestruction::Bind`=0x7615760 及 UNiagaraDataInterfaceChaosDestruction 族（0x7615760 邻域 0x7611000–0x7620000）：物理破坏→粒子生成数据接口，属通用 Chaos Niagara，不涉及角色颜色/Spine。

**结论**：追 Spine 颜色脉冲链时本卷只需作为"不在场证明"排除项；0x70b25f0/0x70b2424/0x70c0d30 本体应在地址 < 0x7405194 的更早分卷，0x9dbadd4/0x9110a64/0xa0e5800 在 > 0x8c5defc 的更晚分卷。
