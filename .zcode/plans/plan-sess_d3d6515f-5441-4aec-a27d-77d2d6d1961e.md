# 龙卡全息后处理 1:1 复刻计划（纯静态逆向路线）

## 目标
用 libUE4.so 静态逆向拿到全部运行时常量与生成规则（COLOR0 顶点色、TEXCOORD1.zw 生成规则、MixColor/ScanLineColor/DarkenRatio/ DistortTime 等 uniform 真值），在 DRCSpineDye 框架里以**线性空间 1:1 公式**复刻完整全息链（含扫描线动画、噪声 UV 扰动、屏幕投影蒙版、去饱和压暗分支），替换现有的 gamma 空间手工拟合版。

## 现状（已确认的事实基础）
- **权威着色器源码在手**：shadercode 包（86154 个 .ushaderbytecode，LZ4@9 可批量解，工具已写）含 Spine 材质家族全部 60 个变体，含 §12.3 重建的完整全息 FS（ps0 BASE / ps1 投影 / ps2 MASK 三纹理 + pc2_h 参数块）
- **染料色在已有资产里**：`unpacked/chr_ling001_mask.png`（ps2 的 MASK 贴图，1024×512）——全息 FS 的染料色 = mask 采样色做反色 lerp，这正是"从已有资产算出"的部分
- **运行时锚点充足**（此前未用上）：顶点布局实测 stride=44（attrib0=4f/attrib1=2f/attrib2=3f/attrib3=4×u8）、uniform 块实测值模式（1/960 等）、GLES 函数是 libUE4.so 的 .dynsym 导入 → 可反查全部调用点
- `unpacked/so/libUE4.so` = MuMu 实际运行的 x86_64 变体（203MB，剥符号）

## 阶段 0：全息着色器全量再提取（离线，先行）
1. 用现有 LZ4 解码器扫 shadercode 包，按"三纹理采样 + pc2_h + ORIGINAL_POSITION"过滤，导出**完整全息 FS/VS 全家**（不是 §12.3 的手工重组版，而是逐字节原版）
2. 列出全部 uniform 块的精确布局（名称/数组大小/哪个 loc），作为逆向时的字节级对照表

## 阶段 1：libUE4.so 静态逆向（核心，不计成本）
工具：pyelftools 解 ELF + capstone 线性反汇编 .text（pip 安装）；深度函数反编译用 Ghidra 便携版 headless 单函数导入分析（D 盘无现成，需下载）

锚点链（每步都有可验证的中间产物）：
1. **GLES 导入表** → 找 `glVertexAttribPointer` 的 PLT → 线性扫描 .text 找全部调用点
2. 过滤：调用前立即数 **stride=44(0x2C)**、attrib index 0-3、GL_UNSIGNED_BYTE(0x1401) 的调用点 → Spine 顶点填充点（预计个位数）
3. 回溯函数边界 → 反编译顶点填充函数 → 读出：
   - **TEXCOORD1.zw 的生成规则**（预期：从 attachment 的 region 元数据/mask 页 UV 计算——这是"新皮肤零捕获"的关键）
   - **COLOR0 的来源链**（实例字段 → 常量池 FLinearColor，或配置表）
4. **uniform 填充函数**：同理经 `glUniform4fv` 调用点 + 块布局对照（pc0_h=(1/960,-1/540,-0.005,…) 等实测模式做字节级校验，确认找对函数）→ 读出 MixColor/ScanLineColor/混合比/DarkenRatio/DistorTime 的真值或其来源（配置表/常量池）
5. 每个常量做**双重校验**：数值合理性 + 与实测 uniform 日志（pass1-3 已有部分值）交叉印证

时间预算：Ghidra 全量分析 203MB 需数小时（后台跑）；capstone 定向路线预计先出结果。失败备选（明确检查点）：锚点链若在第 2 步穷尽（找不到 stride=44 调用点），回退方案再向你确认（届时再议运行时捕获或 Ghidra 全量深挖）。

## 阶段 2：权威 gdshader v2（全息完整复刻）
以原版 GLSL 为蓝本 1:1 移植到 `shader_type canvas_item`：
- **线性空间管线**：base 采样 sRGB→线性解码 → COLOR0（sRGB 解码后的顶点色）→ 网格量化权重（h3=256−128×pc0_h[0].x）反色 lerp → **ps2 mask 采样**（用逆向出的 uv1.zw 规则换算成 UV0 的纯函数逐像素算；若规则依赖逐顶点独立数据则烘成数据贴图通道）→ MixColor/扫描线链 → sRGB 编码
- **动画项**：扫描线波形（fract(屏幕Y+time×速度)）、噪声 UV 扰动、屏幕投影 alpha 蒙版——时间基准用 Godot 内建 TIME
- 两种表现分支（pu_m[1].x 去饱和压暗 开/关）做成 config 开关，默认按逆向出的游戏实际值
- profile schema v2：+mask 贴图 +全息参数组；皮肤包仍 100% 原始资产
