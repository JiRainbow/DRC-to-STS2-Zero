# 2.0 源码公式零失真实现（试衣间小图=战斗 共用路径定案）

## 核心结论（本轮侦察，全部源码/资产实证）
1. **小图路径**：`ViewAppearanceFightSpine` → `ViewSpineWidget:_Load` → `CSpineResCfg.materialId=0` → material=nil → **保留 WBP 内置 NormalBlendMaterial**。试衣间用 hologram 变体 WBP，内置材质=`M_UI_TEST_Inst`（§12.22 已读出），**12 项参数全部静态提取在案**（MixColor=(0.071,0.620,0.766,0.171)、ScanLineColor=(0.491,0.739,1.0,0)、DarkenRatio=0.7、ScanLine 系、RenderOpacity=1）。
2. **战斗路径**：BP → V2 材质（BP 转储已确认无参数覆盖，染料运行时值静态不可得）。
3. **用户观察"小图==战斗"** ⇒ 两者运行时观感等价 ⇒ **2.0 采用常量完备的 M_UI_TEST_Inst 公式**作为实现目标——同时描述小图与战斗，V2 染料值问题绕开。
4. **公式族同构**（三材质源码同一结构，用户反色假说的精确形式）：
   `out = encode( max( (A − rgb)·w + rgb·MixColor , 0 ) )`，区域选择 = mask.a；alpha = base.a·C0.a·Opacity
5. **无需 tonemap**：小图是 UI 渲染（无 tonemap）却与战斗一致 ⇒ 本作走移动 LDR 路径，材质内 encode 即最终色（E 报告的 tonemap 结论只适用 HDR 分支；§12.20 pu_m 实测 encode ON 吻合）。
6. **MPC 真值入库**（本轮新提取）：PointLight 双灯默认关（radius=0）、DarkenMPC MaxDarkenAlpha=0（压暗关）、LightParam 全组（DirectLightColor=(1,1,1) 等）——静止态光照项全零，**画面=纯材质公式**，与 1.0 的观感对比基准自洽。
